## Completed in the working tree

- Board pin ownership is fixed at CLK/CMD/D0/D1/D2/D3/CD =
  P2/P3/P4/P5/P10/P11/P6; P6 presence is active low and optional U3 must remain
  NC.
- One-bit advertises `SDIO_CAPS_1BIT_ONLY`; four-bit advertises
  `SDIO_CAPS_4BIT`, but both initially enumerate in one-bit mode so NuttX owns
  the ACMD6 transition.
- HPWORK supplies standard insertion/ejection callbacks with 100 ms polling.
- Separate MCUboot validation profiles enforce the S1 route contract.
- The FAT validator performs bounded mount/write/fsync/reopen/read/verify/
  remove/unmount and one eject/reinsert repetition; it never formats media.
- Both CP/AP profile pairs pass preflight.  Both one-bit and four-bit AP
  profiles complete clean compile/link, and their resolved configurations and
  final ELF semantics have been checked.
- The one-bit MCUboot pair has completed a full signed dual-image build with
  version `18.6.48` and security counter `102`.  Factory and RPTUN layout
  checks passed, and the package remains bound to the merged public trust
  contract.
- `build_dual_image.sh --help` is side-effect free and unknown arguments now
  fail before any configuration or build.
- The two development signing identities were originally generated by the
  project workflow and left only under temporary names.  When those names
  disappeared, explicitly approved current-domain alias copies were found and
  matched against all three recorded public fingerprints.  The working names
  are restored for this session; no replacement key or trust-root rotation was
  performed.
