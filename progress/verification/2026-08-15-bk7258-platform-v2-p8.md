# P8 AIDK AI Toy board verification

Date: 2026-08-15

Scope: the official existing `board/bk7258` Board layer and the host-only
framework/resource-graph metadata for the schematic-only AIDK AI Toy target.

## Contract

- `CONFIG_BK7258_BOARD_AIDK_AI_TOY` is the sole new board selector.  CMake and
  Classic Make select `boards/aidk_ai_toy`; no config profile directory was
  added.
- `bk7258_board_config.h` binds UART0 at 115200 8N1 for console/download,
  disables flow control, SWD, boot hold, RTT and RTS/DTR reset, and marks the
  USB serial port as dynamic.  The board config and resource graph keep board
  identity separate from a host COM or `/dev` path.
- The bring-up hook is intentionally no-device and returns `OK`; unknown BOM
  peripherals are not claimed.  P20/P21, P0/P1, P8/P9 and USB0 conflicts are
  recorded as unknown/do-not-claim constraints.  `hardware_verified` remains
  false.
- The AIDK product has an exact board/product/mode SDK set and lock using the
  existing content-addressed CP/AP metadata; BL2 remains no-runtime-SDK.

## Host-only checks

Commands run from the repository root:

```text
python3 -m unittest -v board/bk7258/tests/test_bk7258_framework.py board/bk7258/tests/test_bk7258_resource_graph.py board/bk7258/tests/test_bk7258_aidk.py
python3 board/bk7258/scripts/bk7258_framework.py --root . build-plan --product aidk_ai_toy_bringup --out /tmp/aidk-plan.json
python3 board/bk7258/scripts/bk7258_resource_graph.py --root . --graph board/bk7258/scripts/bk7258_resource_graph_aidk_ai_toy.json graph-check
python3 board/bk7258/scripts/bk7258_resource_graph.py --root . --graph board/bk7258/scripts/bk7258_resource_graph_aidk_ai_toy.json graph-resolve --out /tmp/aidk-graph-resolved.json
git diff --check
```

The CMake and Classic contracts were inspected for positive variant wiring;

Flash or boot operation was used.
