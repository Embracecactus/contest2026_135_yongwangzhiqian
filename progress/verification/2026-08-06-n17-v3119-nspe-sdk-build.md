# N17 v3.1.1.9 Non-Secure SDK bundle build

- Date: 2026-08-06
- Result: CP PASS; AP BLOCKED by official SDK source build failure
- Hardware/firmware mutation: none
- SDK/NuttX/apps source changes: none in their original trees

## Scope

Determine whether the official v3.1.1.9 SDK can produce a Non-Secure static
library bundle suitable for the staged BK7258 BL2/TF-M route. This is a build
compatibility result only; it does not produce a BL2 image or authorize a
board write.

## Method and results

An isolated temporary copy of v3.1.1.9 retained `CONFIG_TZ=y` and changed only
the CP and AP project settings from `CONFIG_SPE=1` to `CONFIG_SPE=0`. Both
targets used the official command form with the installed toolchain:

```sh
make bk7258_cp PROJECT=app COMPILER_TOOLCHAIN_PATH=/usr/bin -j32
make bk7258_ap PROJECT=app COMPILER_TOOLCHAIN_PATH=/usr/bin -j32
```

CP passed. Its generated `sdkconfig.h` contains `CONFIG_TZ=1` and
`CONFIG_SPE=0`; the generated build selected `libwifi_nspe.a`,
`libbk_phy_nspe.a`, and
`libbluetooth_controller_controller_only_ble_nspe.a`. It also compiled the
official `ARM_CM33_NTZ/non_secure` FreeRTOS port. The resulting temporary
`app.bin` was 979 KiB. This artifact remains outside the repository and has
not been imported.

AP failed during the official SDK source build. `cli_dma.c` and
`middleware/soc/bk7258_ap/hal/sys_pm_hal.c` call
`bk_dma_check_chn_status()` while `-Werror` reports it as implicitly declared;
the function implementation is present in `general_dma/dma_driver.c`. No SDK
source workaround was applied.

## Conclusion and boundary

The CP Non-Secure static-library route is technically buildable from official
v3.1.1.9. The AP security state remains an open official-platform question:
do not assume that CP and AP can both use `SPE=0`, and do not replace the
active project bundle until Beken supplies the supported AP configuration or
explicitly confirms AP remains Secure in the BL2/TF-M topology.

The original SDK tree, project SDK bundle, NuttX/apps trees, Flash, OTP/eFuse
and board state were not modified.
