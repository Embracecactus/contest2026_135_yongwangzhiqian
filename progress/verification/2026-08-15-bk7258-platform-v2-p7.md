# BK7258 platform-v2 P7 transport verification

- Date: 2026-08-15
- Branch: `refactor/bk7258-platform-v2`
- Scope: cross-platform dry-run port discovery, resolution and transport plan.

## Implemented

- `bk7258_transport_schema.json` records Linux `/dev/tty*`, macOS
  `/dev/cu.*`, Windows `COM*`, WSL native/optional-PowerShell paths, explicit
  USB identity fields, and no-hardware-access policy.
- `port-list` enumerates candidate names without opening serial devices;
  `port-resolve` accepts explicit ports and rejects ambiguous auto-selection
  unless one deterministic USB identity match remains. Board and port
  identities are separate metadata.
- `transport-plan` models exclusive loader open -> close/release -> console
  open/capture, records RTS/DTR/reset capabilities, and rejects RTS reset in
  AIDK mode. PowerShell is optional and never mandatory.
