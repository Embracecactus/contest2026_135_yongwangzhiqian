# ADR-003 bootloader research archive

These files implement the disabled SRAM sector-copy prototype evaluated by
N15-R2. ADR-003 was never accepted and ADR-004 superseded it before any board
write. The active bootloader Makefile and linker script must not compile or
retain anything in this directory.

The immutable mutation gate in the archived source remains zero. This archive
is evidence, not a supported recovery or OTA implementation.
