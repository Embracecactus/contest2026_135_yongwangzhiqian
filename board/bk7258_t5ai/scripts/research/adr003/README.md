# ADR-003 host research archive

The metadata ABI, 32,915-case journal simulator, old-layout calculator, and
SRAM-closure verifier here belong to the rejected physical-sector-swap
option. They remain reproducible historical evidence but are not gates for
the accepted ADR-004 contiguous A/B implementation.

Run archived tools from this directory only when reviewing ADR-003 evidence;
do not use their addresses for packaging or flashing.
