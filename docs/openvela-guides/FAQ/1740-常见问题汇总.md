# 一、 openvela 应用开发语言

openvela 支持以下开发语言：

  - 原生应用：C/C++

  - 快应用：JavaScript

# 二、 Xiaomi Vela 和 openvela 的关系

openvela 是 Xiaomi Vela 的开源版本，两者基于同一套代码实现。

# 三、 openvela 使用的代码风格检查工具版本是什么

openvela 项目使用 **clang-format 14** 版本进行代码风格检查。
