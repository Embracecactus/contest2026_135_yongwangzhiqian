# 声学模型 API

声学模型（Sound Model）接口用于处理媒体触发器所需的低层声学模型数据，提供模型加载、卸载、属性/选项查询和热词检测能力。

头文件：<span class="reference">\#include \<media\_trigger\_model.h\></span>

# openvela 实现说明

  - **与 Media Trigger 的关系**：<span class="reference">media\_trigger\_\*</span> 是高层语音唤醒接口（含 DSP 通路），<span class="reference">media\_trigger\_model\_\*</span> 是底层模型操作接口（不涉及音频采集）
  - **典型用途**：自定义识别流程、在特定 PCM 缓冲上跑一次性的关键词检测
  - **模型属性/选项**：通过 <span class="reference">get\_properties</span> 查询厂商属性，<span class="reference">get\_options</span> 读取推荐的音频采样参数
  - **一次性检测**：<span class="reference">detect\_hotword</span> 在给定 PCM 缓冲上做一次同步检测

# 模型生命周期

## media\_trigger\_model\_load

    void* media_trigger_model_load(const void* model, size_t size);

加载声学模型数据，返回模型上下文。

**参数**：

  - <span class="reference">model</span> 模型数据起始指针。
  - <span class="reference">size</span> 模型数据字节数。

**返回值**：

成功时返回模型上下文指针，失败时返回 <span class="reference">NULL</span>。

## media\_trigger\_model\_unload

    void media_trigger_model_unload(void* context);

卸载已加载的模型上下文。

**参数**：

  - <span class="reference">context</span> 待卸载的模型上下文。

# 模型属性查询

## media\_trigger\_model\_get\_properties

    void media_trigger_model_get_properties(void* properties, size_t* size);

查询厂商提供的模型属性信息。

**参数**：

  - <span class="reference">properties</span> 输出缓冲区，用于存放属性数据。
  - <span class="reference">size</span> 输入输出参数：调用时表示缓冲区大小，返回时被更新为实际写入的字节数。

## media\_trigger\_model\_get\_options

    void media_trigger_model_get_options(void* context, char* options, size_t size);

查询模型推荐的音频采集选项字符串，例如 <span class="reference">"format=s16le:sample\_rate=16000:ch\_layout=mono"</span>。

**参数**：

  - <span class="reference">context</span> 模型上下文（由 <span class="reference">media\_trigger\_model\_load</span> 返回）。
  - <span class="reference">options</span> 输出缓冲区，用于接收选项字符串。
  - <span class="reference">size</span> 输出缓冲区字节数。

## media\_trigger\_model\_get\_buffer\_size

    void media_trigger_model_get_buffer_size(void* context, size_t* size);

查询模型推荐的录音缓冲区大小。

**参数**：

  - <span class="reference">context</span> 模型上下文。
  - <span class="reference">size</span> 输出参数，返回推荐的缓冲区字节数。

# 热词检测

## media\_trigger\_model\_detect\_hotword

    bool media_trigger_model_detect_hotword(void* context, const char* buffer, size_t size);

在给定 PCM 缓冲上运行一次模型检测，判断是否匹配到热词。

**参数**：

  - <span class="reference">context</span> 模型上下文。
  - <span class="reference">buffer</span> 待检测的 PCM 音频缓冲区。
  - <span class="reference">size</span> 缓冲区字节数。

**返回值**：

检测到热词时返回 <span class="reference">true</span>，未检测到返回 <span class="reference">false</span>。
