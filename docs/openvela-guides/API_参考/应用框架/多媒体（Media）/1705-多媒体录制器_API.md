# 多媒体录制器 API

音视频录制功能，支持文件录制和缓冲模式。

头文件：<span class="reference">\#include \<media\_recorder.h\></span>

# openvela 实现说明

  - **同步/异步双模型**：<span class="reference">media\_recorder\_\*</span>（同步）和 <span class="reference">media\_uv\_recorder\_\*</span>（异步，基于 libuv）
  - **输出方式**：支持两种目标
      - 本地文件：通过 <span class="reference">prepare(url)</span> 指定路径
      - 字节流缓冲：通过 <span class="reference">read\_data</span> 读取，或 <span class="reference">get\_socket</span> 获取底层套接字
  - **拍照**：除音视频录制外，提供 <span class="reference">take\_picture</span> / <span class="reference">start\_picture</span> / <span class="reference">finish\_picture</span> 图片捕获接口
  - **事件回调**：通过 <span class="reference">set\_event\_callback</span> 注册事件监听器

# 同步接口 - 生命周期

## media\_recorder\_open

    void* media_recorder_open(const char* params);

打开指定源类型的录制器。

**参数**：

  - <span class="reference">params</span> 源类型常量，通常为 <span class="reference">MEDIA\_SOURCE\_MIC</span>。

**返回值**：

成功时返回录制器句柄，失败时返回 <span class="reference">NULL</span>。

## media\_recorder\_close

    int media_recorder_close(void* handle);

关闭录制器。

**参数**：

  - <span class="reference">handle</span> 录制器句柄。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_recorder\_set\_event\_callback

    int media_recorder_set_event_callback(void* handle, void* cookie, media_event_callback event_cb);

设置录制器事件回调，当状态变化或发生用户关注的事件时触发回调。

**参数**：

  - <span class="reference">handle</span> 录制器句柄。
  - <span class="reference">cookie</span> 用户数据，在 <span class="reference">event\_cb</span> 触发时回传给用户。
  - <span class="reference">event\_cb</span> 事件回调函数。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_recorder\_prepare

    int media_recorder_prepare(void* handle, const char* url, const char* options);

准备录制器。

**参数**：

  - <span class="reference">handle</span> 录制器句柄。
  - <span class="reference">url</span> 资源路径，支持两种模式：1. URL 模式：<span class="reference">url</span> 为本地文件路径，框架会打开并录制到该路径；2. BUFFER 模式：<span class="reference">url</span> 为 <span class="reference">NULL</span>，调用方需通过 <span class="reference">media\_recorder\_read\_data()</span> 或 <span class="reference">media\_recorder\_get\_socket()</span> + <span class="reference">read()</span> 持续接收数据。
  - <span class="reference">options</span> 额外配置参数，字段包括：format（封装格式，如 opus/wav）、sample\_rate（采样率）、ch\_layout（声道布局）、b（比特率，如 <span class="reference">"23900"</span>）、vbr（0=固定码率，1=可变码率）、level（编码复杂度，0-10，默认 10）。示例：<span class="reference">"format=opusraw:sample\_rate=16000:ch\_layout=mono:b=32000:vbr=0:level=1"</span>。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_recorder\_reset

    int media_recorder_reset(void* handle);

重置录制器到初始状态。

**参数**：

  - <span class="reference">handle</span> 录制器句柄。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的错误码。

# 同步接口 - 数据流

## media\_recorder\_read\_data

    ssize_t media_recorder_read_data(void* handle, void* data, size_t len);

从录制器读取录制数据。

**参数**：

  - <span class="reference">handle</span> 录制器句柄。
  - <span class="reference">data</span> 数据缓冲区地址。
  - <span class="reference">len</span> 要读取的数据长度（字节）。

**返回值**：

成功时返回读取的字节数，失败时返回负的错误码。

## media\_recorder\_get\_sockaddr

    int media_recorder_get_sockaddr(void* handle, struct sockaddr_storage* addr);

获取缓冲模式的 Socket 地址信息。

**参数**：

  - <span class="reference">handle</span> 录制器句柄。
  - <span class="reference">addr</span> 用于存储 Socket 地址信息的输出参数。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的错误码。

## media\_recorder\_get\_socket

    int media_recorder_get_socket(void* handle);

获取用于读取的 Socket 文件描述符。

**参数**：

  - <span class="reference">handle</span> 录制器句柄。

**返回值**：

成功时返回 Socket 文件描述符，失败时返回负的错误码。

## media\_recorder\_close\_socket

    void media_recorder_close_socket(void* handle);

关闭录制器数据接收完成后的 Socket 文件描述符。

**参数**：

  - <span class="reference">handle</span> 录制器句柄。

# 同步接口 - 图片捕获

## media\_recorder\_take\_picture

    int media_recorder_take_picture(char* params, char* filename, size_t number);

从摄像头拍照。

**参数**：

  - <span class="reference">params</span> 相机打开路径参数。
  - <span class="reference">filename</span> 新图片的存储路径。
  - <span class="reference">number</span> 拍摄图片的数量。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_recorder\_start\_picture

    void* media_recorder_start_picture(char* params, char* filename, size_t number, media_event_callback event_cb, void* cookie);

开始拍照，内部依次执行打开、设置事件回调、准备和启动操作。

**参数**：

  - <span class="reference">params</span> 打开参数。
  - <span class="reference">filename</span> 新图片的存储路径。
  - <span class="reference">number</span> 拍摄图片的数量。
  - <span class="reference">event\_cb</span> 处理状态反馈的回调函数。
  - <span class="reference">cookie</span> 用户私有数据。

**返回值**：

成功时返回有效句柄，失败时返回 <span class="reference">NULL</span>。

## media\_recorder\_finish\_picture

    int media_recorder_finish_picture(void* handle);

拍照完成后关闭录制器。

**参数**：

  - <span class="reference">handle</span> 由 <span class="reference">media\_recorder\_start\_picture()</span> 返回的录制器句柄。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的错误码。

# 异步接口（基于 libuv）

以下接口仅在启用 <span class="reference">CONFIG\_LIBUV</span> 时可用。

## media\_uv\_recorder\_open

    void* media_uv_recorder_open(void* loop, const char* source, media_uv_callback on_open, void* cookie);

打开异步录制器。

**参数**：

  - <span class="reference">loop</span> 当前线程的 <span class="reference">uv\_loop\_t\*</span> 事件循环句柄。
  - <span class="reference">source</span> 源类型。
  - <span class="reference">on\_open</span> 打开完成后触发的回调函数。
  - <span class="reference">cookie</span> 回调上下文，供 <span class="reference">on\_open</span>、<span class="reference">on\_event</span>、<span class="reference">on\_close</span> 共用。

**返回值**：

成功时返回录制器句柄，失败时返回 <span class="reference">NULL</span>。

## media\_uv\_recorder\_listen

    int media_uv_recorder_listen(void* handle, media_event_callback on_event);

注册事件监听回调，接收录制状态变化通知。

**参数**：

  - <span class="reference">handle</span> 异步录制器句柄。
  - <span class="reference">on\_event</span> 事件回调函数，在收到通知后调用。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_uv\_recorder\_close

    int media_uv_recorder_close(void* handle, media_uv_callback on_close);

关闭异步录制器。

**参数**：

  - <span class="reference">handle</span> 异步录制器句柄。
  - <span class="reference">on\_close</span> 资源释放完成后触发的回调函数。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_uv\_recorder\_prepare

    int media_uv_recorder_prepare(void* handle, const char* url, const char* options, media_uv_object_callback on_connection, media_uv_callback on_prepare, void* cookie);

准备录制目标文件。

**参数**：

  - <span class="reference">handle</span> 异步录制器句柄。
  - <span class="reference">url</span> 目标路径。
  - <span class="reference">options</span> 目标配置参数，详见 <span class="reference">media\_recorder\_prepare</span>。
  - <span class="reference">on\_connection</span> BUFFER 模式下接收可写入数据的 <span class="reference">uv\_pipe\_t</span> 的回调函数。
  - <span class="reference">on\_prepare</span> 准备完成后的结果回调函数。
  - <span class="reference">cookie</span> 回调上下文参数。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。
