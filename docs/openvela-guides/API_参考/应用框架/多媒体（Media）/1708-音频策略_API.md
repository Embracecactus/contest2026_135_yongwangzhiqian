# 音频策略 API

音频路由、设备管理和模式切换策略。

头文件：<span class="reference">\#include \<media\_policy.h\></span>

# openvela 实现说明

  - **Parameter Framework（PFW）后端**：策略数据通过 openvela PFW 规则引擎管理，运行时可动态切换
  - **同步/异步双模型**：<span class="reference">media\_policy\_\*</span>（同步）和 <span class="reference">media\_uv\_policy\_\*</span>（异步，基于 libuv）
  - **策略类别**：涵盖 5 类运行时控制
      - 音频模式（Audio Mode）：通话、媒体播放、免提等场景切换
      - 设备路由（Device Routing）：启用/禁用、可用性、使用状态
      - 音量控制（Stream Volume）：按音频流类型调整音量
      - 静音（Mute）：全局静音与麦克风静音
      - 通用参数（int/string/include/exclude/contain）：扩展配置读写
  - **订阅机制**：通过 <span class="reference">media\_policy\_subscribe</span> 监听策略变化事件（同步接口独有）
  - **HFP 采样率**：通过 <span class="reference">set\_hfp\_samplerate</span> 调整蓝牙免提音频采样率

# 同步接口 - 音频模式

## media\_policy\_set\_audio\_mode

    int media_policy_set_audio_mode(const char* mode);

设置音频模式（如通话模式、正常模式）。

**参数**：

  - <span class="reference">mode</span> 模式常量

**返回值**：

成功时返回 0，失败时返回负的错误码。

## media\_policy\_get\_audio\_mode

    int media_policy_get_audio_mode(char* mode, int len);

**参数**：

  - <span class="reference">mode</span> 输出缓冲区。
  - <span class="reference">len</span> 缓冲区长度。

# 同步接口 - 设备使用

## media\_policy\_set\_devices\_use

    int media_policy_set_devices_use(const char* devices);

强制使用指定音频设备或协议。

**参数**：

  - <span class="reference">devices</span> 设备常量，支持多设备，用 "|" 分隔。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_policy\_set\_devices\_unuse

    int media_policy_set_devices_unuse(const char* devices);

取消强制使用音频设备。

**参数**：

  - <span class="reference">devices</span> 设备常量，支持多设备，用 "|" 分隔。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_policy\_get\_devices\_use

    int media_policy_get_devices_use(char* devices, int len);

获取当前强制使用的音频设备。

**参数**：

  - <span class="reference">devices</span> 设备名称字符串，多个设备用 <span class="reference">|</span> 分隔（例如 <span class="reference">"sco"</span>、<span class="reference">"sco|mic"</span>、<span class="reference">"\<none\>"</span>）。
  - <span class="reference">len</span> 缓冲区长度。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_policy\_is\_devices\_use

    int media_policy_is_devices_use(const char* devices, int* use);

检查指定设备是否处于强制使用状态。

**参数**：

  - <span class="reference">devices</span> 设备常量，支持多设备，用 "|" 分隔。
  - <span class="reference">use</span> 设备使用状态：0 表示所有设备均未使用，1 表示至少有一个设备正在使用。

# 同步接口 - HFP 采样率与设备可用性

## media\_policy\_set\_hfp\_samplerate

    int media_policy_set_hfp_samplerate(int rate);

设置 HFP 蓝牙通话采样率。HFP（Hands-Free Profile）基于 BT-SCO 传输，采样率在协商完成前不确定。

**参数**：

  - <span class="reference">rate</span> 采样率，CVSD 编码取 8000，mSBC 编码取 16000。

**返回值**：
