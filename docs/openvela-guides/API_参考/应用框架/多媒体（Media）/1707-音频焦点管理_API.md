# 音频焦点管理 API

音频焦点（Audio Focus）用于协调多个音频应用之间的播放优先级。当多个应用同时请求音频焦点时，系统根据场景（scenario）判断谁应当播放、谁应当停止或降低音量，并通过回调通知各应用。

头文件：<span class="reference">\#include \<media\_focus.h\></span>

# openvela 实现说明

  - **场景优先级**：通过 <span class="reference">scenario</span> 字符串标识请求类型（如 <span class="reference">MEDIA\_SCENARIO\_MUSIC</span>、<span class="reference">MEDIA\_SCENARIO\_NOTIFICATION</span> 等），框架根据场景优先级返回焦点建议
  - **同步/异步双模型**：提供两组接口
      - 同步：<span class="reference">media\_focus\_\*</span> 系列，适合简单场景
      - 异步（基于 libuv）：<span class="reference">media\_uv\_focus\_\*</span> 系列，需启用 <span class="reference">CONFIG\_LIBUV</span>，适合基于 uv\_loop 的应用
  - **自动回复**：<span class="reference">request2</span> 接口新增 <span class="reference">auto\_reply</span> 参数，为 <span class="reference">1</span> 时框架自动回复收到的建议，无需应用手动调用 <span class="reference">reply</span>
  - **回调失联保护**：即使 <span class="reference">initial\_suggestion</span> 返回 <span class="reference">MEDIA\_FOCUS\_STOP</span>（意味着立即被其他焦点抢占），框架仍会返回有效句柄，必须调用 <span class="reference">abandon</span> 释放，否则会有资源泄漏
  - **新旧接口**：<span class="reference">media\_focus\_request</span> / <span class="reference">media\_uv\_focus\_request</span> 已标记 deprecated，请使用带 <span class="reference">2</span> 后缀的新版本

# 焦点请求（同步）

## media\_focus\_request

    void* media_focus_request(int* initial_suggestion, const char* scenario,
                              media_focus_callback on_suggestion, void* cookie)
        __attribute__((deprecated));

请求音频焦点（**已废弃**，请使用 <span class="reference">media\_focus\_request2</span>）。

**参数**：

  - <span class="reference">initial\_suggestion</span> 输出参数，返回初始焦点建议，取值为 <span class="reference">MEDIA\_FOCUS\_\*</span> 常量。
  - <span class="reference">scenario</span> 场景标识字符串，取值为 <span class="reference">MEDIA\_SCENARIO\_\*</span> 常量。
  - <span class="reference">on\_suggestion</span> 焦点建议变化时的回调函数。
  - <span class="reference">cookie</span> 传递给回调的用户数据。

**返回值**：

成功时返回焦点句柄，失败时返回 <span class="reference">NULL</span>。

**注意**：

  - 若 <span class="reference">initial\_suggestion</span> 为 <span class="reference">MEDIA\_FOCUS\_STOP</span>，<span class="reference">on\_suggestion</span> 不会被调用，但仍会返回有效句柄，调用方必须调用 <span class="reference">media\_focus\_abandon</span> 释放，否则会泄漏。

## media\_focus\_request2

    void* media_focus_request2(int* initial_suggestion, const char* scenario,
                               media_focus_callback2 on_suggestion,
                               int auto_reply, void* cookie);

请求音频焦点（推荐使用，替代 <span class="reference">media\_focus\_request</span>）。

**参数**：

  - <span class="reference">initial\_suggestion</span> 输出参数，返回初始焦点建议，取值为 <span class="reference">MEDIA\_FOCUS\_\*</span> 常量。
  - <span class="reference">scenario</span> 场景标识字符串，取值为 <span class="reference">MEDIA\_SCENARIO\_\*</span> 常量。
  - <span class="reference">on\_suggestion</span> 焦点建议变化时的回调函数（新版签名包含 <span class="reference">req\_id</span>）。
  - <span class="reference">auto\_reply</span> 是否启用自动回复：<span class="reference">1</span> 表示框架自动回复焦点建议，<span class="reference">0</span> 表示由应用手动调用 <span class="reference">media\_focus\_reply</span>。
  - <span class="reference">cookie</span> 传递给回调的用户数据。

**返回值**：

成功时返回焦点句柄，失败时返回 <span class="reference">NULL</span>。

**注意**：

  - 若 <span class="reference">initial\_suggestion</span> 为 <span class="reference">MEDIA\_FOCUS\_STOP</span>，<span class="reference">on\_suggestion</span> 不会被调用，但仍会返回有效句柄，调用方必须调用 <span class="reference">media\_focus\_abandon</span> 释放。

**示例**：  

    int initial_suggestion;
    
    context->handle = media_focus_request2(&initial_suggestion,
        MEDIA_SCENARIO_MUSIC, demo_focus_callback, 1, context);
    if (!context->handle) {
        // 处理错误
    }
    
    if (initial_suggestion == MEDIA_FOCUS_STOP)
        media_focus_abandon(context->handle);

## media\_focus\_abandon

    int media_focus_abandon(void* handle);

释放音频焦点。

**参数**：

  - <span class="reference">handle</span> 待释放的焦点句柄。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的错误码。

## media\_focus\_reply

    int media_focus_reply(void* handle, int req_id);

回复焦点请求。当 <span class="reference">request2</span> 的 <span class="reference">auto\_reply</span> 为 <span class="reference">0</span> 时使用，手动确认焦点建议。

**参数**：

  - <span class="reference">handle</span> 焦点句柄。
  - <span class="reference">req\_id</span> 请求 ID，由焦点建议回调传入。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

# 焦点请求（异步，基于 libuv）

以下接口仅在启用 <span class="reference">CONFIG\_LIBUV</span> 时可用。

## media\_uv\_focus\_request

    void* media_uv_focus_request(void* loop, const char* scenario,
                                 media_focus_callback on_suggestion, void* cookie)
        __attribute__((deprecated));

异步请求音频焦点（**已废弃**，请使用 <span class="reference">media\_uv\_focus\_request2</span>）。

**参数**：

  - <span class="reference">loop</span> 当前线程的 <span class="reference">uv\_loop\_t\*</span> 事件循环。
  - <span class="reference">scenario</span> 场景标识字符串，取值为 <span class="reference">MEDIA\_SCENARIO\_\*</span> 常量。
  - <span class="reference">on\_suggestion</span> 焦点建议变化时的回调函数。
  - <span class="reference">cookie</span> 传递给回调的用户数据。

**返回值**：

成功时返回异步焦点句柄，失败时返回 <span class="reference">NULL</span>。

**注意**：

  - 当 <span class="reference">on\_suggestion</span> 回调收到 <span class="reference">MEDIA\_FOCUS\_STOP</span> 时，应用应调用 <span class="reference">media\_uv\_focus\_abandon</span> 释放句柄。

## media\_uv\_focus\_request2

    void* media_uv_focus_request2(void* loop, const char* scenario,
                                  media_focus_callback2 on_suggestion,
                                  int auto_reply, void* cookie);

异步请求音频焦点（推荐使用，替代 <span class="reference">media\_uv\_focus\_request</span>）。

**参数**：

  - <span class="reference">loop</span> 当前线程的 <span class="reference">uv\_loop\_t\*</span> 事件循环。
  - <span class="reference">scenario</span> 场景标识字符串，取值为 <span class="reference">MEDIA\_SCENARIO\_\*</span> 常量。
  - <span class="reference">on\_suggestion</span> 焦点建议变化时的回调函数（新版签名包含 <span class="reference">req\_id</span>）。
  - <span class="reference">auto\_reply</span> 是否启用自动回复：<span class="reference">1</span> 表示框架自动回复焦点建议。
  - <span class="reference">cookie</span> 传递给回调的用户数据。

**返回值**：

成功时返回异步焦点句柄，失败时返回 <span class="reference">NULL</span>。

**示例**：  

    void user_on_suggestion(int suggestion, int req_id, void* cookie) {
        UserContext* ctx = cookie;
        switch (suggestion) {
        case MEDIA_FOCUS_STOP:
            media_uv_focus_abandon(ctx->handle, NULL);
            break;
        }
    }
    
    ctx->handle = media_uv_focus_request2(loop, MEDIA_SCENARIO_MUSIC,
        user_on_suggestion, 1, ctx);

## media\_uv\_focus\_abandon

    int media_uv_focus_abandon(void* handle, media_uv_callback on_abandon);

异步释放音频焦点。

**参数**：

  - <span class="reference">handle</span> 异步焦点句柄。
  - <span class="reference">on\_abandon</span> 释放完成后的回调，通常用于释放 cookie。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_uv\_focus\_reply

    int media_uv_focus_reply(void* handle, int req_id);

异步回复焦点请求。当 <span class="reference">request2</span> 的 <span class="reference">auto\_reply</span> 为 <span class="reference">0</span> 时使用。

**参数**：

  - <span class="reference">handle</span> 异步焦点句柄。
  - <span class="reference">req\_id</span> 请求 ID。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。
