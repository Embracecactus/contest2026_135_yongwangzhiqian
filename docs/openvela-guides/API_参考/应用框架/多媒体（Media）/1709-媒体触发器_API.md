# 媒体触发器 API

媒体触发器（Media Trigger）用于语音唤醒（Voice Trigger）场景，通过加载声学模型实现关键词检测、启动识别等功能。

头文件：<span class="reference">\#include \<media\_trigger.h\></span>

# openvela 实现说明

  - **典型场景**：智能音箱、智能手表的"嘿小爱"等语音唤醒
  - **工作流程**：
    1.  <span class="reference">open</span> 打开触发器句柄
    2.  <span class="reference">set\_event\_callback</span> 注册事件回调
    3.  <span class="reference">load\_sound\_model</span> 加载声学模型
    4.  <span class="reference">start\_recognition</span> 开始识别
    5.  监听回调，检测到关键词后处理
    6.  <span class="reference">stop\_recognition</span> → <span class="reference">unload\_sound\_model</span> → <span class="reference">close</span> 清理
  - **参数配置**：通过 <span class="reference">open</span> 传入的 <span class="reference">params</span> 选择麦克风配置（如 <span class="reference">"default"</span> / <span class="reference">"Dual Mic"</span>）
  - **底层实现**：对接 DSP 侧的声学模型处理器

# 触发器生命周期

## media\_trigger\_open

    void* media_trigger_open(const char* params);

打开媒体触发器句柄。

**参数**：

  - <span class="reference">params</span> 触发器参数字符串，例如 <span class="reference">"default"</span> 或 <span class="reference">"Dual Mic"</span>，用于选择麦克风配置。

**返回值**：

成功时返回触发器句柄，失败时返回 <span class="reference">NULL</span>。

**示例**：  

    // 1. 创建实例
    void* handle = media_trigger_open("default");
    
    // 2. 设置事件回调
    ret = media_trigger_set_event_callback(handle, cookie, callback);
    
    // 3. 加载声学模型
    ret = media_trigger_load_sound_model(handle, model, model_size);
    
    // 4. 开始识别
    ret = media_trigger_start_recognition(handle);
    
    // 5. 停止识别
    ret = media_trigger_stop_recognition(handle);
    
    // 6. 卸载模型
    ret = media_trigger_unload_sound_model(handle);
    
    // 7. 关闭句柄
    ret = media_trigger_close(handle);

## media\_trigger\_close

    int media_trigger_close(void* handle);

关闭触发器句柄，释放相关资源。

**参数**：

  - <span class="reference">handle</span> 待关闭的触发器句柄。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

# 事件与回调

## media\_trigger\_set\_event\_callback

    int media_trigger_set_event_callback(void* handle, void* event_cookie,
                                         media_event_callback on_event);

为触发器设置事件回调，用于接收识别状态变化等事件。

**参数**：

  - <span class="reference">handle</span> 触发器句柄。
  - <span class="reference">event\_cookie</span> 传递给回调的用户数据。
  - <span class="reference">on\_event</span> 事件回调函数。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

# 声学模型管理

## media\_trigger\_load\_sound\_model

    int media_trigger_load_sound_model(void* handle, void* model, size_t model_size);

为触发器加载声学模型数据。

**参数**：

  - <span class="reference">handle</span> 触发器句柄。
  - <span class="reference">model</span> 声学模型数据指针。
  - <span class="reference">model\_size</span> 模型数据字节数。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_trigger\_unload\_sound\_model

    int media_trigger_unload_sound_model(void* handle);

卸载已加载的声学模型。

**参数**：

  - <span class="reference">handle</span> 触发器句柄。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

# 识别控制

## media\_trigger\_start\_recognition

    int media_trigger_start_recognition(void* handle);

开始语音识别。触发器会持续检测输入音频，匹配已加载模型中的关键词。

**参数**：

  - <span class="reference">handle</span> 触发器句柄。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_trigger\_stop\_recognition

    int media_trigger_stop_recognition(void* handle);

停止语音识别。

**参数**：

  - <span class="reference">handle</span> 触发器句柄。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

    int media_trigger_get_property(char* properties, int len);

查询触发器底层 DSP 的属性信息。

  - <span class="reference">len</span> 缓冲区长度。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。
