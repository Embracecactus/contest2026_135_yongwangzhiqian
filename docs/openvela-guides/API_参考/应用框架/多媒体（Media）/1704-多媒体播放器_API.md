# 多媒体播放器 API

音视频播放功能，支持本地文件和网络流媒体。

头文件：<span class="reference">\#include \<media\_player.h\></span>

# openvela 实现说明

  - **同步/异步双模型**：提供两套对等接口
      - 同步：<span class="reference">media\_player\_\*</span> 系列，调用在当前线程返回
      - 异步：<span class="reference">media\_uv\_player\_\*</span> 系列，基于 libuv 事件循环，需启用 <span class="reference">CONFIG\_LIBUV</span>
  - **生命周期**：<span class="reference">open</span> 创建播放器 → <span class="reference">prepare</span> 设置源 → <span class="reference">start</span> 开始播放 → <span class="reference">stop</span>/<span class="reference">close</span> 释放
  - **数据源**：支持两种输入方式
      - 本地/网络 URL：通过 <span class="reference">prepare(url)</span> 直接指定
      - 字节流缓冲：通过 <span class="reference">write\_data</span> 推送，或 <span class="reference">get\_socket</span> 获取底层套接字
  - **事件回调**：通过 <span class="reference">set\_event\_callback</span> 注册事件监听器，接收播放状态变化、错误等通知
  - **参数配置**：通用参数通过 <span class="reference">set\_property</span> / <span class="reference">get\_property</span> 读写（如采样率、通道数等）

# 同步接口 - 生命周期

## media\_player\_open

    void* media_player_open(const char* stream);

打开指定流类型的播放器。

**参数**：

  - <span class="reference">stream</span> 流类型常量，不同流类型有不同的路由逻辑。

**返回值**：

成功时返回播放器句柄，失败时返回 <span class="reference">NULL</span>。

## media\_player\_close

    int media_player_close(void* handle, int pending_stop);

关闭播放器。

**参数**：

  - <span class="reference">handle</span> 播放器句柄。
  - <span class="reference">pending\_stop</span> 关闭前是否等待停止完成：0 表示立即停止并关闭，1 表示等待当前曲目播放完成再关闭。此参数仅对音频播放器有效；视频播放器设置为 1 时不产生等待效果。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_player\_set\_event\_callback

    int media_player_set_event_callback(void* handle, void* event_cookie, media_event_callback on_event);

设置事件回调，监听流状态变更。

**参数**：

  - <span class="reference">handle</span> 播放器句柄。
  - <span class="reference">event\_cookie</span> 回调上下文参数。
  - <span class="reference">on\_event</span> 事件回调函数，用于接收流状态变化通知。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的错误码。

## media\_player\_prepare

    int media_player_prepare(void* handle, const char* url, const char* options);

准备播放资源。

**参数**：

  - <span class="reference">handle</span> 播放器句柄。
  - <span class="reference">url</span> 资源路径，支持两种模式：1. URL 模式：<span class="reference">url</span> 为本地文件路径或网络地址，框架会读取并播放；2. BUFFER 模式：<span class="reference">url</span> 为 <span class="reference">NULL</span>，调用方需通过 <span class="reference">media\_player\_write\_data()</span> 或 <span class="reference">media\_player\_get\_socket()</span> + <span class="reference">write()</span> 持续推送数据。
  - <span class="reference">options</span> 资源的额外配置参数，通常为描述资源格式的键值对（例如 <span class="reference">"format=s16le,sample\_rate=44100,channels=2"</span>）。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的错误码。

## media\_player\_reset

    int media_player_reset(void* handle);

重置播放器到初始状态。

**参数**：

  - <span class="reference">handle</span> 播放器句柄，由 <span class="reference">media\_player\_open</span> 返回。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的错误码。

# 异步接口（基于 libuv）

以下接口仅在启用 <span class="reference">CONFIG\_LIBUV</span> 时可用，回调在 <span class="reference">uv\_loop</span> 上执行，避免阻塞调用线程。

## media\_uv\_player\_open

    void* media_uv_player_open(void* loop, const char* stream, media_uv_callback on_open, void* cookie);

打开异步播放器。

**参数**：

  - <span class="reference">loop</span> 当前线程的 <span class="reference">uv\_loop\_t\*</span> 事件循环句柄。
  - <span class="reference">stream</span> 流类型常量，不同流类型有不同的路由逻辑。
  - <span class="reference">on\_open</span> 打开完成后触发的回调函数。
  - <span class="reference">cookie</span> 回调上下文，供 <span class="reference">on\_open</span>、<span class="reference">on\_event</span>、<span class="reference">on\_connection</span>、<span class="reference">on\_close</span> 共用。

**返回值**：

成功时返回播放器句柄，失败时返回 <span class="reference">NULL</span>。

## media\_uv\_player\_listen

    int media_uv_player_listen(void* handle, media_event_callback on_event);

注册事件监听回调，接收播放状态变化通知。

**参数**：

  - <span class="reference">handle</span> 异步播放器句柄。
  - <span class="reference">on\_event</span> 事件回调函数，在收到通知后调用。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

## media\_uv\_player\_close

    int media_uv_player_close(void* handle, int pending, media_uv_callback on_close);

关闭异步播放器。

**参数**：

  - <span class="reference">handle</span> 异步播放器句柄。
  - <span class="reference">pending</span> 是否以 pending 方式关闭（等待当前播放完成）。
  - <span class="reference">on\_close</span> 资源释放完成后触发的回调函数。

**返回值**：

成功时返回 <span class="reference">0</span>，无效句柄时返回负的错误码。

## media\_uv\_player\_prepare

    int media_uv_player_prepare(void* handle, const char* url, const char* options, media_uv_object_callback on_connection, media_uv_callback on_prepare, void* cookie);

准备音频源以供播放。

**参数**：

  - <span class="reference">handle</span> 异步播放器句柄。
  - <span class="reference">url</span> 资源路径，支持两种模式：1. URL 模式：<span class="reference">url</span> 为本地文件路径或网络地址，框架会读取并播放；2. BUFFER 模式：<span class="reference">url</span> 为 <span class="reference">NULL</span>，调用方需通过 <span class="reference">media\_player\_write\_data()</span> 或 <span class="reference">media\_player\_get\_socket()</span> + <span class="reference">write()</span> 持续推送数据。
  - <span class="reference">options</span> 资源的额外配置参数，通常为描述资源格式的键值对（例如 <span class="reference">"format=s16le,sample\_rate=44100,channels=2"</span>）。
  - <span class="reference">on\_connection</span> BUFFER 模式下接收 <span class="reference">uv\_pipe\_t</span> 的回调函数。
  - <span class="reference">on\_prepare</span> 准备完成后的结果回调函数。
  - <span class="reference">cookie</span> 回调上下文参数。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的错误码。
