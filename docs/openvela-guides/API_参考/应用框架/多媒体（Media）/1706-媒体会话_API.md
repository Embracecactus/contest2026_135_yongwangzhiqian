# 媒体会话 API

媒体播放控制和状态同步，支持控制器-被控端模式。

头文件：<span class="reference">\#include \<media\_session.h\></span>

# openvela 实现说明

  - **控制器-被控端模式**：支持两种角色
      - 控制器（Controller）：通过 <span class="reference">media\_session\_open</span> 打开，向当前活跃媒体发送播放控制命令
      - 被控端（Controllee）：通过 <span class="reference">media\_session\_register</span> 注册，接收控制命令并上报状态
  - **同步/异步双模型**：<span class="reference">media\_session\_\*</span>（同步）和 <span class="reference">media\_uv\_session\_\*</span>（异步，基于 libuv）
  - **控制命令**：start / stop / pause / seek / prev\_song / next\_song / volume 等
  - **状态查询**：控制器可查询当前播放状态、位置、时长、音量等
  - **状态通知**：被控端通过 <span class="reference">notify</span> / <span class="reference">update</span> 向控制器推送播放状态变化

  - <span class="reference">cookie</span> 回调上下文参数。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。
