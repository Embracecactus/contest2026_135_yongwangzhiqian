# 媒体工具 API

媒体框架通用工具接口，包括 DTMF 双音多频信号生成、事件名查询、图/策略 dump 与通用命令发送。

头文件：<span class="reference">\#include \<media\_utils.h\></span>

# openvela 实现说明

  - **DTMF**：生成 <span class="reference">0-9</span> / <span class="reference">\*\#ABCD</span> 对应的 DTMF 双音多频信号，音频格式固定为 <span class="reference">format=s16le:sample\_rate=8000:ch\_layout=mono</span>（由 <span class="reference">MEDIA\_TONE\_DTMF\_FORMAT</span> 宏定义）
  - **调试接口**：<span class="reference">media\_graph\_dump</span>、<span class="reference">media\_player\_dump</span>、<span class="reference">media\_recorder\_dump</span> 和 <span class="reference">media\_policy\_dump</span> 用于打印内部状态，便于问题定位
  - **通用命令**：<span class="reference">media\_process\_command</span> 向 media server 发送自定义命令，用于扩展能力（如触发 graph 内某个 filter 的操作）
  - **事件名查询**：<span class="reference">media\_event\_get\_name</span> 把 <span class="reference">MEDIA\_EVENT\_\*</span> 数值转成可读字符串，便于日志输出

# DTMF 信号生成

## media\_dtmf\_get\_buffer\_size

    int media_dtmf_get_buffer_size(const char* numbers);

查询 DTMF 信号所需的缓冲区大小。

**参数**：

  - <span class="reference">numbers</span> 拨号按键字符序列，字符范围为 <span class="reference">0-9</span> 与 <span class="reference">\*\#ABCD</span>。

**返回值**：

成功时返回缓冲区字节数，失败时返回负的 errno。

## media\_dtmf\_generate

    int media_dtmf_generate(const char* numbers, void* buffer);

生成一个或连续多个 DTMF 信号并写入调用方提供的缓冲区。

**参数**：

  - <span class="reference">numbers</span> 拨号按键字符序列，字符范围为 <span class="reference">0-9</span> 与 <span class="reference">\*\#ABCD</span>。
  - <span class="reference">buffer</span> 输出缓冲区，大小需通过 <span class="reference">media\_dtmf\_get\_buffer\_size</span> 提前查询。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。

**注意**：

  - 播放 DTMF 音时，音频参数必须固定为 <span class="reference">MEDIA\_TONE\_DTMF\_FORMAT</span>（<span class="reference">s16le / 8000Hz / mono</span>）。

# 事件名查询

## media\_event\_get\_name

    const char* media_event_get_name(int event);

将 <span class="reference">MEDIA\_EVENT\_\*</span> 枚举值转换为可读的字符串。

**参数**：

  - <span class="reference">event</span> 事件值，取值为 <span class="reference">MEDIA\_EVENT\_\*</span> 常量。

**返回值**：

始终返回可打印的字符串，对未知事件返回占位字符串（不会返回 <span class="reference">NULL</span>）。

**示例**：  

    printf("event: %s\n", media_event_get_name(MEDIA_EVENT_STARTED));
    // 输出: event: STARTED

# 通用命令

## media\_process\_command

    int media_process_command(const char* target, const char* cmd,
                              const char* arg, char* res, int res_len);

向 media server 内的指定 graph filter 发送自定义命令。

**参数**：

  - <span class="reference">target</span> 目标 graph filter 实例名。
  - <span class="reference">cmd</span> 命令类型。
  - <span class="reference">arg</span> 命令参数。
  - <span class="reference">res</span> 响应消息输出缓冲区。
  - <span class="reference">res\_len</span> 响应缓冲区长度。

**返回值**：

成功时返回 <span class="reference">0</span>，失败时返回负的 errno。
