# Services API

Services 模块提供 openvela 系统的核心应用管理服务，包括 Activity Manager Service（AMS）和 Package Manager Service（PMS），负责应用生命周期管理、任务调度及包管理等功能。

  - **[AMS](https://doc.openvela.com/document?id=1714&version=dev-ai-contest-2026&language=cn)** — Activity Manager Service，应用/Activity 生命周期管理
  - **[PMS](https://doc.openvela.com/document?id=1715&version=dev-ai-contest-2026&language=cn)** — Package Manager Service，应用包管理
