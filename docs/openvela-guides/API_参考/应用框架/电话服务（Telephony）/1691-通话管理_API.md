# 通话管理 API

语音通话控制，包括拨号、接听、挂断、保持等。

头文件：<span class="reference">\#include \<tapi\_call.h\></span>

# openvela 实现说明

  - **SIM 卡标识**：部分接口不带 <span class="reference">slot\_id</span>，使用默认卡；需要指定卡时通过 <span class="reference">tapi\_call\_set\_default\_slot</span> 切换
  - **同步/异步**：拨号、应答等耗时操作同时提供同步版本和 <span class="reference">\_async</span> 版本（回调风格）
  - **按 ID 操作**：长生命周期通话通过返回的 call ID（字符串）唯一标识，<span class="reference">\*\_by\_id</span> 接口据此执行操作
  - **DTMF**：拨号盘按键通过 <span class="reference">tapi\_call\_send\_tones</span>（批量）或 <span class="reference">tapi\_call\_start\_dtmf</span> / <span class="reference">tapi\_call\_stop\_dtmf</span>（持续按键）触发
  - **会议通话**：通过 <span class="reference">tapi\_call\_dial\_conferece</span> 和 <span class="reference">tapi\_call\_merge\_call</span> 组织，<span class="reference">tapi\_call\_separate\_call</span> 拆分

## tapi\_call\_dial

    int tapi_call_dial(tapi_context context, int slot_id, char* number, int hide_callerid, int event_id, tapi_async_function p_handle);

发起语音通话。

**参数**：

  - <span class="reference">context</span> Telephony 上下文句柄。
  - <span class="reference">slot\_id</span> SIM 卡槽 ID（0 或 1）。
  - <span class="reference">number</span> 电话号码。
  - <span class="reference">hide\_callerid</span> 是否隐藏主叫号码。
  - <span class="reference">event\_id</span> 事件 ID，用于回调匹配。
  - <span class="reference">p\_handle</span> 异步回调函数。

**返回值**：

成功时返回 0，失败时返回负的错误码。
