# 数据连接 API

蜂窝数据连接管理。

头文件：<span class="reference">\#include \<tapi\_data.h\></span>

# openvela 实现说明

  - **APN 上下文**：通过 <span class="reference">tapi\_data\_\*\_apn\_context</span> 系列接口管理 APN 配置（增删改查）
  - **按需连接**：<span class="reference">tapi\_data\_request\_network</span> / <span class="reference">tapi\_data\_release\_network</span> 控制数据网络的建立与释放
  - **漫游控制**：通过 <span class="reference">tapi\_data\_enable\_roaming</span> 显式开关数据漫游
  - **SIM 卡标识**：涉及特定卡的操作使用 <span class="reference">slot\_id</span> 参数；数据默认卡通过 <span class="reference">tapi\_data\_set\_default\_slot</span> 设置
  - **状态订阅**：<span class="reference">tapi\_data\_register</span> / <span class="reference">tapi\_data\_unregister</span> 用于注册/取消状态变化事件
