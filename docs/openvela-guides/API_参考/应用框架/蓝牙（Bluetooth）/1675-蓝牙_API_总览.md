# 蓝牙 API

openvela 蓝牙框架提供完整的蓝牙协议栈接口，支持经典蓝牙（BR/EDR）和低功耗蓝牙（BLE），涵盖从底层连接管理到上层应用规范。

# 核心协议

  - **[GAP](https://doc.openvela.com/document?id=1676&version=dev-ai-contest-2026&language=cn)**（通用访问规范）— 设备发现、连接管理、配对与安全
  - **[GATT](https://doc.openvela.com/document?id=1677&version=dev-ai-contest-2026&language=cn)**（通用属性规范）— BLE 数据属性读写与通知
  - **[设备管理](https://doc.openvela.com/document?id=1678&version=dev-ai-contest-2026&language=cn)** — 远程设备配对、连接、属性查询

# 经典蓝牙规范

  - **[A2DP](https://doc.openvela.com/document?id=1681&version=dev-ai-contest-2026&language=cn)**（高级音频分发）— 高质量立体声音乐传输
  - **[HFP](https://doc.openvela.com/document?id=1683&version=dev-ai-contest-2026&language=cn)**（免提规范）— 蓝牙通话功能
  - **[HID](https://doc.openvela.com/document?id=1684&version=dev-ai-contest-2026&language=cn)**（人机接口设备）— 键盘、鼠标、游戏手柄
  - **[SPP](https://doc.openvela.com/document?id=1685&version=dev-ai-contest-2026&language=cn)**（串口仿真）— 数据透传
  - **[PAN](https://doc.openvela.com/document?id=1686&version=dev-ai-contest-2026&language=cn)**（个人局域网）— 网络共享与蓝牙组网

# 低功耗蓝牙规范

  - **[CS](https://github.com/open-vela/docs/tree/dev-ai-contest-2026//https:/github.com/open-vela/docs/blob/dev/zh-cn/api/framework/bluetooth/bt_cs.md)**（Channel Sounding）— 蓝牙信道探测测距与定位
