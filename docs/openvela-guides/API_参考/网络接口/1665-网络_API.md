# 网络 API

openvela 提供与 BSD 兼容的套接字接口，支持 IPv4（<span class="reference">AF\_INET</span>）、IPv6（<span class="reference">AF\_INET6</span>）等协议族，以及流套接字（<span class="reference">SOCK\_STREAM</span>）、数据报套接字（<span class="reference">SOCK\_DGRAM</span>）和原始套接字（<span class="reference">SOCK\_RAW</span>）。

头文件：<span class="reference">\#include \<sys/socket.h\></span>、<span class="reference">\#include \<netinet/in.h\></span>、<span class="reference">\#include \<arpa/inet.h\></span>

# openvela 实现说明

  - **协议族支持**：<span class="reference">AF\_INET</span>（IPv4）、<span class="reference">AF\_INET6</span>（IPv6）、<span class="reference">AF\_LOCAL</span>/<span class="reference">AF\_UNIX</span>（本地套接字）、<span class="reference">AF\_PACKET</span>（原始链路层）等，具体取决于网络栈配置
  - **配置依赖**：网络子系统是可选的，需要启用 <span class="reference">CONFIG\_NET</span> 及相关协议配置（如 <span class="reference">CONFIG\_NET\_TCP</span>、<span class="reference">CONFIG\_NET\_UDP</span>）
  - **非阻塞 I/O**：通过 <span class="reference">fcntl(fd, F\_SETFL, O\_NONBLOCK)</span> 或 <span class="reference">SOCK\_NONBLOCK</span> 标志设置
  - **DNS 解析**：需要启用 <span class="reference">CONFIG\_NETDB\_DNSCLIENT</span>，通过 <span class="reference">nuttx/net/dns.h</span> 接口管理 DNS 服务器

# 套接字创建与管理

## socket

    int socket(int domain, int type, int protocol);

创建一个通信端点（套接字），返回文件描述符。

**参数**：

  - <span class="reference">domain</span> 协议族：
  - <span class="reference">AF\_INET</span> IPv4
  - <span class="reference">AF\_INET6</span> IPv6
  - <span class="reference">AF\_LOCAL</span> / <span class="reference">AF\_UNIX</span> 本地套接字
  - <span class="reference">AF\_PACKET</span> 原始链路层
  - <span class="reference">type</span> 套接字类型：
  - <span class="reference">SOCK\_STREAM</span> 面向连接的流套接字（TCP）
  - <span class="reference">SOCK\_DGRAM</span> 无连接的数据报套接字（UDP）
  - <span class="reference">SOCK\_RAW</span> 原始套接字
  - 可与 <span class="reference">SOCK\_NONBLOCK</span>、<span class="reference">SOCK\_CLOEXEC</span> 按位或组合
  - <span class="reference">protocol</span> 协议编号，通常为 0（自动选择）。也可指定 <span class="reference">IPPROTO\_TCP</span>、<span class="reference">IPPROTO\_UDP</span> 等。

**返回值**：

成功时返回非负文件描述符，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EAFNOSUPPORT</span> 不支持的协议族。
  - <span class="reference">EPROTONOSUPPORT</span> 不支持的协议类型。
  - <span class="reference">EMFILE</span> 进程文件描述符数量已达上限。
  - <span class="reference">ENOMEM</span> 内存不足。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## socketpair

    int socketpair(int domain, int type, int protocol, int sv[2]);

创建一对已连接的套接字，常用于父子进程间通信。

**参数**：

  - <span class="reference">domain</span> 协议族，通常为 <span class="reference">AF\_LOCAL</span>。
  - <span class="reference">type</span> 套接字类型（<span class="reference">SOCK\_STREAM</span> 或 <span class="reference">SOCK\_DGRAM</span>）。
  - <span class="reference">protocol</span> 通常为 0。
  - <span class="reference">sv</span> 输出参数，存储两个已连接的文件描述符。

**返回值**：

成功时返回 0，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EAFNOSUPPORT</span> 不支持的协议族。
  - <span class="reference">EMFILE</span> 文件描述符数量已达上限。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## shutdown

    int shutdown(int sockfd, int how);

关闭套接字的部分或全部通信方向。与 <span class="reference">close()</span> 不同，<span class="reference">shutdown()</span> 可以只关闭读或写方向。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">how</span> 关闭方式：
  - <span class="reference">SHUT\_RD</span> 关闭读方向。
  - <span class="reference">SHUT\_WR</span> 关闭写方向（发送 FIN）。
  - <span class="reference">SHUT\_RDWR</span> 关闭读写双向。

**返回值**：

成功时返回 0，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> 无效的文件描述符。
  - <span class="reference">ENOTCONN</span> 套接字未连接。
  - <span class="reference">EINVAL</span> <span class="reference">how</span> 参数无效。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

# 连接管理

## bind

    int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen);

将套接字绑定到指定的本地地址和端口。服务器端在 <span class="reference">listen()</span> 前必须调用 <span class="reference">bind()</span>。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">addr</span> 本地地址结构体（<span class="reference">struct sockaddr\_in</span> 或 <span class="reference">struct sockaddr\_in6</span>）。
  - <span class="reference">addrlen</span> 地址结构体的大小。

**返回值**：

成功时返回 0，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> 无效的文件描述符。
  - <span class="reference">EINVAL</span> 套接字已绑定，或地址无效。
  - <span class="reference">EADDRINUSE</span> 地址已被使用。
  - <span class="reference">EADDRNOTAVAIL</span> 请求的地址不可用。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## connect

    int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen);

发起到远程地址的连接。对于 TCP 套接字，执行三次握手；对于 UDP 套接字，设置默认目标地址。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">addr</span> 远程地址结构体。
  - <span class="reference">addrlen</span> 地址结构体的大小。

**返回值**：

成功时返回 0，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> 无效的文件描述符。
  - <span class="reference">ECONNREFUSED</span> 远程主机拒绝连接。
  - <span class="reference">ETIMEDOUT</span> 连接超时。
  - <span class="reference">ENETUNREACH</span> 网络不可达。
  - <span class="reference">EINPROGRESS</span> 非阻塞模式下连接正在进行。
  - <span class="reference">EISCONN</span> 套接字已连接。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## listen

    int listen(int sockfd, int backlog);

将套接字标记为被动监听状态，准备接受连接请求。

**参数**：

  - <span class="reference">sockfd</span> 已绑定的套接字文件描述符。
  - <span class="reference">backlog</span> 等待连接队列的最大长度。

**返回值**：

成功时返回 0，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> 无效的文件描述符。
  - <span class="reference">EOPNOTSUPP</span> 套接字类型不支持 <span class="reference">listen()</span>。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## accept

    int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);

从监听套接字的等待队列中取出第一个连接请求，创建并返回一个新的已连接套接字。如果队列为空，阻塞等待。

**参数**：

  - <span class="reference">sockfd</span> 监听套接字文件描述符。
  - <span class="reference">addr</span> 如果非 <span class="reference">NULL</span>，存储客户端地址。
  - <span class="reference">addrlen</span> 输入时为 <span class="reference">addr</span> 缓冲区大小，输出时为实际地址大小。

**返回值**：

成功时返回新的已连接套接字描述符，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> 无效的文件描述符。
  - <span class="reference">EMFILE</span> 文件描述符数量已达上限。
  - <span class="reference">ECONNABORTED</span> 连接被中止。
  - <span class="reference">EINTR</span> 被信号中断。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## accept4

    int accept4(int sockfd, struct sockaddr *addr, socklen_t *addrlen, int flags);

与 <span class="reference">accept()</span> 相同，但可通过 <span class="reference">flags</span> 设置新套接字的属性。

**参数**：

  - <span class="reference">sockfd</span> 监听套接字文件描述符。
  - <span class="reference">addr</span> 客户端地址（可为 <span class="reference">NULL</span>）。
  - <span class="reference">addrlen</span> 地址长度。
  - <span class="reference">flags</span> 标志位：
  - <span class="reference">SOCK\_NONBLOCK</span> 新套接字设为非阻塞。
  - <span class="reference">SOCK\_CLOEXEC</span> 新套接字设为 exec 时关闭。

**返回值**：

同 <span class="reference">accept()</span>。

**POSIX 兼容性**：兼容 Linux 扩展接口（非 POSIX 标准）。

# 数据发送

## send

    ssize_t send(int sockfd, const void *buf, size_t len, int flags);

在已连接的套接字上发送数据。等价于 <span class="reference">sendto()</span> 不指定目标地址。

**参数**：

  - <span class="reference">sockfd</span> 已连接的套接字文件描述符。
  - <span class="reference">buf</span> 要发送的数据缓冲区。
  - <span class="reference">len</span> 数据长度（字节）。
  - <span class="reference">flags</span> 发送标志：
  - <span class="reference">MSG\_DONTWAIT</span> 非阻塞发送。
  - <span class="reference">MSG\_NOSIGNAL</span> 对端关闭时不产生 <span class="reference">SIGPIPE</span>。
  - <span class="reference">0</span> 默认行为。

**返回值**：

成功时返回发送的字节数，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> 无效的文件描述符。
  - <span class="reference">ENOTCONN</span> 套接字未连接。
  - <span class="reference">EAGAIN</span> / <span class="reference">EWOULDBLOCK</span> 非阻塞模式下发送缓冲区满。
  - <span class="reference">EPIPE</span> 对端已关闭连接。
  - <span class="reference">EINTR</span> 被信号中断。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## sendto

    ssize_t sendto(int sockfd, const void *buf, size_t len, int flags,
                   const struct sockaddr *to, socklen_t tolen);

发送数据到指定地址。主要用于 UDP 套接字，也可用于已连接的 TCP 套接字（此时忽略目标地址）。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">buf</span> 数据缓冲区。
  - <span class="reference">len</span> 数据长度。
  - <span class="reference">flags</span> 发送标志（同 <span class="reference">send()</span>）。
  - <span class="reference">to</span> 目标地址。对于已连接套接字可为 <span class="reference">NULL</span>。
  - <span class="reference">tolen</span> 目标地址长度。

**返回值**：

成功时返回发送的字节数，失败时返回 -1 并设置 <span class="reference">errno</span>（同 <span class="reference">send()</span>，另加）：

  - <span class="reference">EDESTADDRREQ</span> 未连接的套接字且未指定目标地址。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## sendmsg

    ssize_t sendmsg(int sockfd, const struct msghdr *msg, int flags);

通过 <span class="reference">msghdr</span> 结构发送数据，支持分散/聚集 I/O 和辅助数据（如文件描述符传递）。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">msg</span> 消息头结构体，包含目标地址、I/O 向量、辅助数据等。
  - <span class="reference">flags</span> 发送标志。

**返回值**：

成功时返回发送的字节数，失败时返回 -1 并设置 <span class="reference">errno</span>。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

# 数据接收

## recv

    ssize_t recv(int sockfd, void *buf, size_t len, int flags);

从已连接的套接字接收数据。

**参数**：

  - <span class="reference">sockfd</span> 已连接的套接字文件描述符。
  - <span class="reference">buf</span> 接收缓冲区。
  - <span class="reference">len</span> 缓冲区大小（字节）。
  - <span class="reference">flags</span> 接收标志：
  - <span class="reference">MSG\_DONTWAIT</span> 非阻塞接收。
  - <span class="reference">MSG\_PEEK</span> 查看数据但不移除。
  - <span class="reference">MSG\_WAITALL</span> 等待接收完整的 <span class="reference">len</span> 字节。
  - <span class="reference">0</span> 默认行为。

**返回值**：

成功时返回接收的字节数（0 表示对端关闭连接），失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> 无效的文件描述符。
  - <span class="reference">ENOTCONN</span> 套接字未连接。
  - <span class="reference">EAGAIN</span> / <span class="reference">EWOULDBLOCK</span> 非阻塞模式下无数据可读。
  - <span class="reference">EINTR</span> 被信号中断。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## recvfrom

    ssize_t recvfrom(int sockfd, void *buf, size_t len, int flags,
                     struct sockaddr *from, socklen_t *fromlen);

接收数据并获取发送方地址。主要用于 UDP 套接字。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">buf</span> 接收缓冲区。
  - <span class="reference">len</span> 缓冲区大小。
  - <span class="reference">flags</span> 接收标志（同 <span class="reference">recv()</span>）。
  - <span class="reference">from</span> 如果非 <span class="reference">NULL</span>，存储发送方地址。
  - <span class="reference">fromlen</span> 输入时为 <span class="reference">from</span> 缓冲区大小，输出时为实际地址大小。

**返回值**：

成功时返回接收的字节数，失败时返回 -1 并设置 <span class="reference">errno</span>（同 <span class="reference">recv()</span>）。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## recvmsg

    ssize_t recvmsg(int sockfd, struct msghdr *msg, int flags);

通过 <span class="reference">msghdr</span> 结构接收数据，支持分散/聚集 I/O 和辅助数据。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">msg</span> 消息头结构体。
  - <span class="reference">flags</span> 接收标志。

**返回值**：

成功时返回接收的字节数，失败时返回 -1 并设置 <span class="reference">errno</span>。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

# 套接字选项

## setsockopt

    int setsockopt(int sockfd, int level, int option, const void *value, socklen_t value_len);

设置套接字选项。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">level</span> 选项所在的协议层：
  - <span class="reference">SOL\_SOCKET</span> 套接字层选项。
  - <span class="reference">IPPROTO\_TCP</span> TCP 层选项。
  - <span class="reference">IPPROTO\_IP</span> IP 层选项。
  - <span class="reference">IPPROTO\_IPV6</span> IPv6 层选项。
  - <span class="reference">option</span> 选项名称（如 <span class="reference">SO\_REUSEADDR</span>、<span class="reference">SO\_KEEPALIVE</span>、<span class="reference">TCP\_NODELAY</span> 等）。
  - <span class="reference">value</span> 选项值。
  - <span class="reference">value\_len</span> 选项值的大小。

**返回值**：

成功时返回 0，失败时返回 -1 并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> 无效的文件描述符。
  - <span class="reference">ENOPROTOOPT</span> 不支持的选项。
  - <span class="reference">EINVAL</span> 选项值无效。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## getsockopt

    int getsockopt(int sockfd, int level, int option, void *value, socklen_t *value_len);

获取套接字选项。

**参数**：

  - <span class="reference">sockfd</span> 套接字文件描述符。
  - <span class="reference">level</span> 协议层（同 <span class="reference">setsockopt()</span>）。
  - <span class="reference">option</span> 选项名称。
  - <span class="reference">value</span> 存储选项值的缓冲区。
  - <span class="reference">value\_len</span> 输入时为缓冲区大小，输出时为实际值大小。

**返回值**：

成功时返回 0，失败时返回 -1 并设置 <span class="reference">errno</span>（同 <span class="reference">setsockopt()</span>）。

**POSIX 兼容性**：兼容 POSIX/BSD 同名接口。

## dns\_register\_notify

    int dns_register_notify(dns_callback_t callback, void *arg);

注册 DNS 服务器变更通知。当 DNS 服务器列表发生变化时，调用回调函数。

**参数**：

  - <span class="reference">callback</span> 变更通知回调函数。
  - <span class="reference">arg</span> 传递给回调函数的用户参数。

**返回值**：

成功时返回 0，失败时返回负的错误码。

**POSIX 兼容性**：openvela/NuttX 扩展接口。

## dns\_unregister\_notify

    int dns_unregister_notify(dns_callback_t callback, void *arg);

取消 DNS 服务器变更通知注册。

**参数**：

  - <span class="reference">callback</span> 之前注册的回调函数。
  - <span class="reference">arg</span> 注册时提供的用户参数。

**返回值**：

成功时返回 0，失败时返回负的错误码。

**POSIX 兼容性**：openvela/NuttX 扩展接口。

## dns\_set\_queryfamily

    int dns_set_queryfamily(sa_family_t family);

设置 DNS 查询使用的地址族。

**参数**：

  - <span class="reference">family</span> 地址族（<span class="reference">AF\_INET</span>、<span class="reference">AF\_INET6</span> 或 <span class="reference">AF\_UNSPEC</span>）。

**返回值**：

成功时返回 0，失败时返回负的错误码。

**POSIX 兼容性**：openvela/NuttX 扩展接口。
