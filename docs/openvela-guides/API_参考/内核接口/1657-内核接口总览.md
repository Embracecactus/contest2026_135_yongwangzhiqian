# 内核接口

openvela 内核基于 Apache NuttX RTOS，提供符合 POSIX 标准的系统接口，涵盖进程/线程管理、任务调度、内存管理、信号机制、消息队列等核心功能。本章节详细介绍各内核子系统的 API 接口及使用说明。

  - **[线程管理](https://doc.openvela.com/document?id=1658&version=dev-ai-contest-2026&language=cn)** — POSIX Thread (pthread) 接口
  - **[任务调度](https://doc.openvela.com/document?id=1659&version=dev-ai-contest-2026&language=cn)** — 调度策略、优先级、任务属性
  - **[内存管理](https://doc.openvela.com/document?id=1660&version=dev-ai-contest-2026&language=cn)** — 堆内存分配、内存池、内存信息查询
  - **[信号机制](https://doc.openvela.com/document?id=1661&version=dev-ai-contest-2026&language=cn)** — POSIX 信号、信号处理、信号集
  - **[消息队列](https://doc.openvela.com/document?id=1662&version=dev-ai-contest-2026&language=cn)** — POSIX 消息队列
