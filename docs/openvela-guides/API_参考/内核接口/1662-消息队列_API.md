# 消息队列 API

openvela 提供符合 POSIX 标准的消息队列接口，用于任务间的异步消息传递。消息队列支持优先级排序，高优先级消息优先被接收。

头文件：<span class="reference">\#include \<mqueue.h\></span>

# openvela 实现说明

  - **中断中发送**：<span class="reference">mq\_send()</span> 可在中断上下文中调用，但行为不同：不检查队列大小，使用预分配消息（数量由 <span class="reference">PREALLOC\_MQ\_IRQ\_MSGS</span> 配置）
  - **通知行为差异**：<span class="reference">mq\_notify()</span> 即使有任务在等待接收消息，仍会发送通知信号，与 POSIX 规范不完全一致
  - **超时时间**：<span class="reference">mq\_timedsend()</span> 和 <span class="reference">mq\_timedreceive()</span> 使用基于 Epoch 的绝对时间

# 队列管理

## mq\_open

    mqd_t mq_open(const char *mqName, int oflags, ...);

在调用任务和消息队列之间建立连接。成功调用后，返回的消息队列描述符可用于后续操作，直到调用 <span class="reference">mq\_close()</span>。

**参数**：

  - <span class="reference">mqName</span> 消息队列的名称。
  - <span class="reference">oflags</span> 打开标志位，可以是以下的任意组合：
  - <span class="reference">O\_RDONLY</span> 只读。
  - <span class="reference">O\_WRONLY</span> 只写。
  - <span class="reference">O\_RDWR</span> 读写。
  - <span class="reference">O\_CREAT</span> 如果消息队列不存在则创建。
  - <span class="reference">O\_EXCL</span> 与 <span class="reference">O\_CREAT</span> 配合，如果队列已存在则失败。
  - <span class="reference">O\_NONBLOCK</span> 非阻塞模式。
  - <span class="reference">...</span> 可选参数，当使用 <span class="reference">O\_CREAT</span> 时需要提供：
  - <span class="reference">mode</span>（<span class="reference">mode\_t</span>）文件权限位。当前实现中未使用，但 POSIX 要求提供。
  - <span class="reference">attr</span>（<span class="reference">struct mq\_attr \*</span>）队列属性。如果为 <span class="reference">NULL</span> 则使用默认值。<span class="reference">mq\_maxmsg</span> 设置最大消息数，<span class="reference">mq\_msgsize</span> 设置最大消息大小。

**返回值**：

成功时返回消息队列描述符（<span class="reference">mqd\_t</span>），失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">ENOENT</span> 未设置 <span class="reference">O\_CREAT</span> 且指定的队列不存在。
  - <span class="reference">EEXIST</span> 同时设置了 <span class="reference">O\_CREAT</span> 和 <span class="reference">O\_EXCL</span>，但队列已存在。
  - <span class="reference">EINVAL</span> 参数无效（如 <span class="reference">mqName</span> 为 <span class="reference">NULL</span>）。
  - <span class="reference">ENOMEM</span> 内存不足，无法创建队列。
  - <span class="reference">ENFILE</span> 系统消息队列数量已达上限。

**POSIX 兼容性**：兼容 POSIX 同名接口。

## mq\_close

    int mq_close(mqd_t mqdes);

关闭消息队列描述符，释放系统分配给该任务的资源。如果任务在该队列上注册了通知请求，通知会被取消。

**参数**：

  - <span class="reference">mqdes</span> 消息队列描述符。

**返回值**：

成功时返回 0，失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> <span class="reference">mqdes</span> 不是有效的消息队列描述符。

**注意**：

  - 在 <span class="reference">mq\_send()</span> 或 <span class="reference">mq\_receive()</span> 阻塞时调用 <span class="reference">mq\_close()</span> 的行为是未定义的。
  - 关闭后再次使用同一 <span class="reference">mqdes</span> 的行为是未定义的。

**POSIX 兼容性**：兼容 POSIX 同名接口。

## mq\_unlink

    int mq_unlink(const char *mqName);

删除指定名称的消息队列。如果有任务仍然打开了该队列，删除会推迟到所有描述符都关闭后执行。

**参数**：

  - <span class="reference">mqName</span> 消息队列的名称。

**返回值**：

成功时返回 0，失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">ENOENT</span> 指定名称的队列不存在。
  - <span class="reference">EINVAL</span> <span class="reference">mqName</span> 为 <span class="reference">NULL</span>。

**POSIX 兼容性**：兼容 POSIX 同名接口。

# 消息发送

## mq\_send

    int mq_send(mqd_t mqdes, const void *msg, size_t msglen, int prio);

将消息发送到消息队列。消息按优先级排序，高优先级消息排在低优先级之前。<span class="reference">prio</span> 不能超过 <span class="reference">MQ\_PRIO\_MAX</span>。

如果队列已满且未设置 <span class="reference">O\_NONBLOCK</span>，调用阻塞直到有空间可用。如果设置了 <span class="reference">O\_NONBLOCK</span>，立即返回错误。

**参数**：

  - <span class="reference">mqdes</span> 消息队列描述符。
  - <span class="reference">msg</span> 要发送的消息。
  - <span class="reference">msglen</span> 消息的字节长度，不能超过 <span class="reference">mq\_msgsize</span>。
  - <span class="reference">prio</span> 消息优先级。

**返回值**：

成功时返回 0，失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">EAGAIN</span> 队列已满且设置了 <span class="reference">O\_NONBLOCK</span>。
  - <span class="reference">EINVAL</span> <span class="reference">msg</span> 或 <span class="reference">mqdes</span> 为 <span class="reference">NULL</span>，或 <span class="reference">prio</span> 无效。
  - <span class="reference">EPERM</span> 消息队列未以写模式打开。
  - <span class="reference">EMSGSIZE</span> <span class="reference">msglen</span> 超过队列的 <span class="reference">mq\_msgsize</span>。
  - <span class="reference">EINTR</span> 被信号中断。

**注意**：

  - <span class="reference">mq\_send()</span> 可在中断上下文中调用，但行为不同：不检查队列大小（总是发送），使用预分配消息（数量由 <span class="reference">PREALLOC\_MQ\_IRQ\_MSGS</span> 配置），不分配新内存。

**POSIX 兼容性**：兼容 POSIX 同名接口。

## mq\_timedsend

    int mq_timedsend(mqd_t mqdes, const void *msg, size_t msglen, int prio,
                     const struct timespec *abstime);

带超时的消息发送。行为与 <span class="reference">mq\_send()</span> 相同，但在队列满时最多阻塞到 <span class="reference">abstime</span> 指定的绝对时间。

**参数**：

  - <span class="reference">mqdes</span> 消息队列描述符。
  - <span class="reference">msg</span> 要发送的消息。
  - <span class="reference">msglen</span> 消息的字节长度。
  - <span class="reference">prio</span> 消息优先级。
  - <span class="reference">abstime</span> 绝对超时时间（基于 Epoch）。

**返回值**：

成功时返回 0，失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">EAGAIN</span> 队列已满且设置了 <span class="reference">O\_NONBLOCK</span>。
  - <span class="reference">EINVAL</span> <span class="reference">msg</span> 或 <span class="reference">mqdes</span> 为 <span class="reference">NULL</span>，或 <span class="reference">prio</span> 无效。
  - <span class="reference">EPERM</span> 消息队列未以写模式打开。
  - <span class="reference">EMSGSIZE</span> <span class="reference">msglen</span> 超过队列的 <span class="reference">mq\_msgsize</span>。
  - <span class="reference">EINTR</span> 被信号中断。
  - <span class="reference">ETIMEDOUT</span> 超时。

**POSIX 兼容性**：兼容 POSIX 同名接口。

# 消息接收

## mq\_receive

    ssize_t mq_receive(mqd_t mqdes, void *msg, size_t msglen, int *prio);

从消息队列接收优先级最高且最早的消息。<span class="reference">msglen</span> 不能小于队列的 <span class="reference">mq\_msgsize</span>，否则返回错误。

如果队列为空且未设置 <span class="reference">O\_NONBLOCK</span>，调用阻塞直到有消息可用。多个等待任务中，优先级最高且等待最久的任务优先接收。

**参数**：

  - <span class="reference">mqdes</span> 消息队列描述符。
  - <span class="reference">msg</span> 接收消息的缓冲区。
  - <span class="reference">msglen</span> 缓冲区大小（字节）。
  - <span class="reference">prio</span> 如果非 <span class="reference">NULL</span>，存储接收到的消息的优先级。

**返回值**：

成功时返回消息长度（字节），失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">EAGAIN</span> 队列为空且设置了 <span class="reference">O\_NONBLOCK</span>。
  - <span class="reference">EPERM</span> 消息队列未以读模式打开。
  - <span class="reference">EMSGSIZE</span> <span class="reference">msglen</span> 小于队列的 <span class="reference">mq\_msgsize</span>。
  - <span class="reference">EINTR</span> 被信号中断。

**POSIX 兼容性**：兼容 POSIX 同名接口。

## mq\_timedreceive

    ssize_t mq_timedreceive(mqd_t mqdes, char *msg, size_t msglen,
                            unsigned int *prio, const struct timespec *abstime);

带超时的消息接收。行为与 <span class="reference">mq\_receive()</span> 相同，但在队列空时最多阻塞到 <span class="reference">abstime</span> 指定的绝对时间。

**参数**：

  - <span class="reference">mqdes</span> 消息队列描述符。
  - <span class="reference">msg</span> 接收消息的缓冲区。
  - <span class="reference">msglen</span> 缓冲区大小（字节）。
  - <span class="reference">prio</span> 如果非 <span class="reference">NULL</span>，存储接收到的消息的优先级。
  - <span class="reference">abstime</span> 绝对超时时间（基于 Epoch）。

**返回值**：

成功时返回消息长度（字节），失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">EAGAIN</span> 队列为空且设置了 <span class="reference">O\_NONBLOCK</span>。
  - <span class="reference">EPERM</span> 消息队列未以读模式打开。
  - <span class="reference">EMSGSIZE</span> <span class="reference">msglen</span> 小于队列的 <span class="reference">mq\_msgsize</span>。
  - <span class="reference">EINTR</span> 被信号中断。
  - <span class="reference">ETIMEDOUT</span> 超时。

**POSIX 兼容性**：兼容 POSIX 同名接口。

# 队列属性

## mq\_setattr

    int mq_setattr(mqd_t mqdes, const struct mq_attr *mqStat, struct mq_attr *oldMqStat);

设置消息队列属性。<span class="reference">mq\_flags</span> 中只有 <span class="reference">O\_NONBLOCK</span> 位可以被修改。

**参数**：

  - <span class="reference">mqdes</span> 消息队列描述符。
  - <span class="reference">mqStat</span> 新属性。
  - <span class="reference">oldMqStat</span> 如果非 <span class="reference">NULL</span>，存储修改前的属性。

**返回值**：

成功时返回 0，失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> <span class="reference">mqdes</span> 不是有效的描述符。
  - <span class="reference">EINVAL</span> <span class="reference">mqStat</span> 为 <span class="reference">NULL</span>。

**POSIX 兼容性**：兼容 POSIX 同名接口。

## mq\_getattr

    int mq_getattr(mqd_t mqdes, struct mq_attr *mqStat);

获取消息队列的当前属性。

**参数**：

  - <span class="reference">mqdes</span> 消息队列描述符。
  - <span class="reference">mqStat</span> 返回属性结构体：
  - <span class="reference">mq\_maxmsg</span> 队列中的最大消息数。
  - <span class="reference">mq\_msgsize</span> 最大消息大小（字节）。
  - <span class="reference">mq\_flags</span> 消息队列标志。
  - <span class="reference">mq\_curmsgs</span> 当前队列中的消息数。

**返回值**：

成功时返回 0，失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> <span class="reference">mqdes</span> 不是有效的描述符。
  - <span class="reference">EINVAL</span> <span class="reference">mqStat</span> 为 <span class="reference">NULL</span>。

**POSIX 兼容性**：兼容 POSIX 同名接口。

# 通知

## mq\_notify

    int mq_notify(mqd_t mqdes, const struct sigevent *notification);

注册或取消消息到达通知。当消息到达先前为空的队列时，向注册的任务发送信号通知。

如果 <span class="reference">notification</span> 为 <span class="reference">NULL</span>，取消当前注册。通知发送后注册自动取消，需要重新注册。

**参数**：

  - <span class="reference">mqdes</span> 消息队列描述符。
  - <span class="reference">notification</span> 通知配置，包括：
  - <span class="reference">sigev\_notify</span> 通知方式（应为 <span class="reference">SIGEV\_SIGNAL</span>）。
  - <span class="reference">sigev\_signo</span> 通知使用的信号编号。
  - <span class="reference">sigev\_value</span> 随信号传递的值。

**返回值**：

成功时返回 0，失败时返回 -1（<span class="reference">ERROR</span>）并设置 <span class="reference">errno</span>：

  - <span class="reference">EBADF</span> <span class="reference">mqdes</span> 不是有效的描述符。
  - <span class="reference">EBUSY</span> 另一个任务已注册了该队列的通知。
  - <span class="reference">EINVAL</span> <span class="reference">sigev\_notify</span> 不是有效值，或信号编号无效。
  - <span class="reference">ENOMEM</span> 内存不足。

**注意**：

  - **与 POSIX 的行为差异**：在 openvela 中，即使有任务正在 <span class="reference">mq\_receive()</span> 上阻塞等待消息，通知信号仍会发送给注册的任务。POSIX 规范要求此时不发送通知（消息直接满足等待的 <span class="reference">mq\_receive()</span>）。

**POSIX 兼容性**：部分兼容 POSIX 同名接口（通知时机与 POSIX 规范有差异）。
