## 2、南向适配层

### 南向接口实现

时钟南向适配需要实现 <span class="reference">struct clk\_ops\_s</span> 接口，以支持以下特性：

| **特性**          | **南向接口**                                              | **作用**                     |
| --------------- | ----------------------------------------------------- | -------------------------- |
| **clk gate**    | <span class="reference">enable</span>                 | 使能时钟。                      |
|                 | <span class="reference">disable</span>                | 关闭时钟。                      |
|                 | <span class="reference">is\_enabled</span>            | 判断时钟是否使能。                  |
| **calc rate**   | <span class="reference">recalc\_rate</span>           | 根据父时钟频率计算当前时钟频率。           |
|                 | <span class="reference">round\_rate</span>            | 根据目标频率，计算合适的频率和父时钟频率。      |
|                 | <span class="reference">determine\_rate</span>        | 根据目标频率，计算最佳频率、最佳父时钟及其频率。   |
| **multiplexer** | <span class="reference">set\_parent</span>            | 设置对应的父时钟。                  |
|                 | <span class="reference">get\_parent</span>            | 获取当前父时钟。                   |
| **set rate**    | <span class="reference">set\_rate</span>              | 根据父时钟频率，配置当前时钟频率。          |
|                 | <span class="reference">set\_rate\_and\_parent</span> | 根据父时钟频率配置当前时钟频率，并选择对应的父时钟。 |
| **phase**       | <span class="reference">get\_phase</span>             | 获取时钟相位。                    |
|                 | <span class="reference">set\_phase</span>             | 设置时钟相位。                    |

  - <span class="reference">struct clk\_ops\_s</span> 定义

以下是 <span class="reference">struct clk\_ops\_s</span> 的定义及其接口参数：  

    struct clk_ops_s
    {
      CODE int       (*enable)(FAR struct clk_s *clk);
      CODE void      (*disable)(FAR struct clk_s *clk);
      CODE int       (*is_enabled)(FAR struct clk_s *clk);
      CODE uint32_t  (*recalc_rate)(FAR struct clk_s *clk, uint32_t parent_rate);
      CODE uint32_t  (*round_rate)(FAR struct clk_s *clk,
                                   uint32_t rate, uint32_t *parent_rate);
      CODE uint32_t  (*determine_rate)(FAR struct clk_s *clk, uint32_t rate,
                                       uint32_t *best_parent_rate,
                                       struct clk_s **best_parent_clk);
      CODE int       (*set_parent)(FAR struct clk_s *clk, uint8_t index);
      CODE uint8_t   (*get_parent)(FAR struct clk_s *clk);
      CODE int       (*set_rate)(FAR struct clk_s *clk, uint32_t rate,
                                 uint32_t parent_rate);
      CODE int       (*set_rate_and_parent)(FAR struct clk_s *clk, uint32_t rate,
                                            uint32_t parent_rate,
                                            uint8_t index);
      CODE int       (*get_phase)(FAR struct clk_s *clk);
      CODE int       (*set_phase)(FAR struct clk_s *clk, int degrees);
    };

  - 时钟节点注册接口

框架提供 <span class="reference">clk\_register</span> 接口，用于注册时钟控制节点。定义如下：  

    FAR struct clk_s *clk_register(FAR const char *name,
                                   FAR const char * const *parent_names,
                                   uint8_t num_parents, uint8_t flags,
                                   FAR const struct clk_ops_s *ops,
                                   FAR void *private_data, size_t private_size)；

##### 参数说明

| **参数**        | **说明**    |
| :------------ | :-------- |
| name          | 时钟单元名称    |
| parent\_names | 父时钟单元名称数组 |
| num\_parents  | 父时钟单元个数   |
| flags         | 时钟单元属性    |
| ops           | 时钟单元控制接口  |
| private\_data | 私有数据      |
| private\_size | 私有数据长度    |

##### 注册属性说明

以下是时钟注册时的属性标志及其说明：

| **flag**                      | **属性说明**                                                                                                                                                                                          |
| :---------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| CLK\_SET\_RATE\_GATE          | 调用 <span class="reference">clk\_set\_rate</span> 设置频率时，需要 gate 当前时钟。                                                                                                                              |
| CLK\_SET\_PARENT\_GATE        | 调用 <span class="reference">clk\_set\_parent</span> 关联非当前父时钟时，需要 gate 当前时钟。                                                                                                                        |
| CLK\_SET\_RATE\_PARENT        | 调用 <span class="reference">clk\_set\_rate</span> 设置频率时，可以变更父时钟及其频率。                                                                                                                               |
| CLK\_SET\_RATE\_NO\_REPARENT  | 设置频率时，不需要重新变更父时钟。                                                                                                                                                                                 |
| CLK\_GET\_RATE\_NOCACHE       | 调用 <span class="reference">clk\_get\_rate</span> 时根据父时钟频率重新计算频率，否则直接从内存结构获取。                                                                                                                      |
| CLK\_NAME\_IS\_STATIC         | 调用 <span class="reference">clk\_register</span> 时，时钟名称为静态内存。                                                                                                                                      |
| CLK\_PARENT\_NAME\_IS\_STATIC | 调用 <span class="reference">clk\_register</span> 时，父时钟名称为静态内存。                                                                                                                                     |
| CLK\_IS\_CRITICAL             | 时钟不允许被关闭。                                                                                                                                                                                         |
| CLK\_OPS\_PARENT\_ENABLE      | 调用 <span class="reference">clk\_set\_parent</span>、<span class="reference">clk\_set\_rate</span>、<span class="reference">clk\_enable</span>、<span class="reference">clk\_disable</span> 时需要使能父时钟。 |

### 3.2 固定系数调频器

    FAR struct clk_s *clk_register_fixed_factor(FAR const char *name,
                                                FAR const char *parent_name,
                                                uint8_t flags, uint8_t mult,
                                                uint8_t div)

  - 调频公式

固定系数调频器的输出频率 (fout) 通过以下公式计算：

<span class="reference">fout = fin \* mult / div</span>  

    fin：父时钟频率。
    mult：倍频因子。
    div：分频因子。
    round_rate 算法

  - <span class="reference">round\_rate</span> 算法用于计算最接近目标频率的输出频率，具体步骤如下：

<!-- end list -->

1.  根据目标输出频率 (<span class="reference">fout</span>) 反推父时钟频率 (<span class="reference">fp</span>)：
    
    fp = fout \* div / mult

2.  对父时钟频率 (<span class="reference">fp</span>) 进行四舍五入，得到最接近的父时钟频率 (<span class="reference">fpbest</span>)。

3.  根据最优父时钟频率 (<span class="reference">fpbest</span>) 计算最优输出频率 (<span class="reference">foutbest</span>)：
    
    foutbest = fpbest \* mult / div

## 4、API接口层

| **API**                     | **功能**                                                                                                                                                    |

# 三、调试PROCFS

通过 <span class="reference">/proc/clk</span> 文件节点，可以查看时钟树的结构关系，以及每个时钟节点的以下信息：

  - enable\_cnt：时钟启用计数。

  - rate：时钟频率。

  - phase：时钟相位。

  - 示例操作

以下是通过 <span class="reference">cat</span> 命令查看 <span class="reference">/proc/clk</span> 文件的示例：  

    ap> cat /proc/clk
       clock                                  enable_cnt        rate       phase
       clk_1000                                         0        1000           0
       clk_2000                                         0        2000           0
    ap>
