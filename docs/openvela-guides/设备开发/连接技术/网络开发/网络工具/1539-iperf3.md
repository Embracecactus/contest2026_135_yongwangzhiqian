# 一、概述

openvela 提供了网络性能测试工具 iperf3，其功能与 iperf2 类似，支持以下特性：

  - 测量 TCP 和 UDP 的带宽质量。
  - 测量 TCP 和 UDP 的最大带宽。
  - 统计带宽、延迟抖动和数据包丢失等信息。

与 iperf2 相比，iperf3 的主要优化点是：

  - 单个服务器可以同时支持 TCP 和 UDP 客户端连接。

# 二、配置说明

在使用 iperf3 工具时，需要在配置文件中启用以下选项：  

    CONFIG_UTILS_IPERF3=y
    CONFIG_UTILS_IPERF3_PRIORITY=89

## 1、配置注意事项

  - perf2 和 iperf3 的互斥性： iperf2 和 iperf3 只能选择其中一个进行编译，同时启用会导致符号冲突。
  - 优先级设置： <span class="reference">CONFIG\_UTILS\_IPERF3\_PRIORITY</span> 的值需要低于网卡驱动线程的优先级，否则可能导致 UDP 客户端行为异常。通常情况下，设置为 89 可以满足绝大多数场景的需求。

# 三、操作使用

## 1、参数说明

### 1.1 通用参数

以下是 iperf3 的常用参数及其功能说明：

  - <span class="reference">-f \[k|m|K|M\]</span>：指定报告显示的单位。
    
      - <span class="reference">k</span> 和 <span class="reference">m</span> 表示以 Kbits 和 Mbits 为单位显示。
    
      - <span class="reference">K</span> 和 <span class="reference">M</span> 表示以 KBytes 和 MBytes 为单位显示。
    
      - 默认单位为 Mbits。
    
      - 示例：  
        
            iperf3 -c 192.0.2.1 -f K

  - <span class="reference">-i sec</span>：指定报告间隔时间（以秒为单位）。
    
      - 示例：  
        
            iperf3 -c 192.0.2.1 -i 2
    
      - 注意：在客户端发送数据时，服务器端显示的是接收速率。建议使用 <span class="reference">-i</span> 参数跟踪速率变化。

  - <span class="reference">-p</span>：指定服务器端使用的端口或客户端连接的端口。
    
      - 示例：  
        
            iperf3 -s -4 -p 5201  
            iperf3 -c 192.0.2.1 -p 5201

  - <span class="reference">-B</span>：绑定到指定的主机地址或接口（适用于多地址或多接口主机）。

### 1.2 服务端专用参数

  - <span class="reference">-D</span>：以服务方式运行 iperf3。
    
      - 示例：  
        
            iperf3 -s -D

  - <span class="reference">-1</span>：被客户端连接一次后自动退出。

  - <span class="reference">-4/-6</span>：监听 IPv4 或 IPv6 地址（默认监听 IPv6）。

### 1.3 客户端专用参数

  - <span class="reference">-u</span>：使用 UDP 协议。

  - <span class="reference">-t sec</span>：指定测试时间（默认 10 秒）。
    
      - 示例：  
        
            iperf3 -c 192.0.2.1 -t 5

  - <span class="reference">-n bytes</span>：指定传输的字节数。
    
      - 示例：  
        
            iperf3 -c 192.0.2.1 -n 100000

  - <span class="reference">-b bandwidth</span>：指定发送带宽（默认 UDP 带宽为 1 Mbit/s）。

  - <span class="reference">--bidir</span>：同时进行双向传输测试。

  - <span class="reference">-l size</span>：指定缓冲区大小。
    
      - 示例：  
        
            iperf3 -c 192.0.2.1 -l 16
    
      - 注意：可以通过调整包长进行测试。

  - <span class="reference">-w size</span>：指定 TCP 窗口大小。窗口过小可能会导致丢包。

  - <span class="reference">-P N</span>：指定并发连接数，发起 N 个同时连接。

  - <span class="reference">-M size</span>：设置 TCP 数据包的 MSS（最大分段大小）。

  - <span class="reference">-N</span>：启用 TCP 不延迟模式。

## 2、启动服务端

运行以下命令以建立常规 socket server：

> **注意**：需要指定 <span class="reference">-4</span> 还是 <span class="reference">-6</span>。

  - 监听 IPv4：  
    
        # 监听IPv4
        iperf3 -s -4 -i 1 -B 127.0.0.1 -p 5201

## 3、启动客户端并连接服务端

运行以下命令以建立常规 socket client 并连接到指定服务器：  

    iperf3 -c 192.0.2.1 -i 1 -p 5201

## 4、注意事项

  - 跨核打流（usrsock）问题。 如果遇到以下提示：  
    
        ERROR: Request %d too large!
    
    说明：单次调用的数据过长（主要见于 TCP）。可以通过减小 <span class="reference">-l</span> 参数值来减少单次发送的数据包长度，从而避免问题。

  - 后台启动进程的终止： 如果以后台方式启动（命令末尾加 <span class="reference">&</span>），可以通过以下命令终止进程：  
    
        kill -2 <iperf3的pid>
    
    该操作等同于按下 <span class="reference">Ctrl+C</span>。

# 五、FAQ

## 1、版本兼容问题

  - openvela 适配版本： 当前 openvela 适配的 iperf3 版本为 3.11。
  - Ubuntu 常见版本： Ubuntu 上常见的 iperf3 版本为 3.9，通常能够正常使用。
  - Windows 版本问题：
      - 避免使用 3.1.3 版本（发布于 2016 年），可能会出现以下不兼容问题：使用 <span class="reference">-n</span> 参数指定数据量时，程序可能在 50 秒后异常退出。
      - 建议下载使用 3.11 版本。
