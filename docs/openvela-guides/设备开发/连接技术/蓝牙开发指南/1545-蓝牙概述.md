# 一、简介

openvela 蓝牙已经通过 Bluetooth 5.4 认证。目前支持的蓝牙能力包括：

  - Core
      - BR/EDR/BLE
      - GAP
      - L2CAP
      - GATT Client/Server
  - A2DP SRC/SNK
  - AVRCP CT/TG
  - HFP AG/HF
  - PAN
  - SPP
  - HID
  - HOGP
  - LEA
      - TMAP
      - CAP
      - BAP/ASCS/PACS/BASS
      - CSIP/CSIS
      - MCP/MCS
      - CCP/TBS
      - VCP/VCS
  - Mesh

openvela 蓝牙目前还能够支持多种开源、闭源协议栈，如Zephyr、Bluez、Bluedroid、Barrot等。

# 二、架构图

![img](https://vela-open-doc.cnbj1.mi-fds.com/vela-open-doc/1781005749556_Bluetooth_arch.png)

  - openvela 蓝牙 Framework 为 <span class="reference">Android Native</span>、可穿戴、音箱和 IoT 等应用提供了统一的编程接口 API。
  - 这些 API 提供的蓝牙能力包括开关、扫描、连接、配对等，均由一套完善的蓝牙服务组件来完成。
  - 为了支持多种协议栈，蓝牙 Framework 定义了一套统一的协议栈适配层接口 <span class="reference">SAL API</span>，使各个三方协议栈，可以方便地接入 openvela。接入新的协议栈时，除了适配 <span class="reference">SAL API</span>，还需要针对 <span class="reference">NuttX</span> 的 <span class="reference">POSIX API</span> 来适配，从而使其可以更高效地运行在 <span class="reference">NuttX</span> 上。

# 四、开发指南

## 1、蓝牙应用开发

对于第三方应用开发者，可以使用 openvela 快应用 QuickApp Feature ，它是基于 QuickJS 引擎使用 C++ 实现的一系列 API 接口，为三方应用提供系统访问能力，更多详情请参见[蓝牙接口](https://doc.quickapp.cn/features/system/bluetooth.html)。

另外，蓝牙 Framework 还提供了 NDK 接口来使用蓝牙系统的所有能力。可以参阅目录 framework/include 中的头文件获取更多信息。

## 2、蓝牙驱动开发

openvela 蓝牙支持多种驱动架构，下文将以目前常用的 BTH4 驱动架构为例，介绍如何实现并注册一个蓝牙驱动。

### 实现驱动

芯片厂商可以实现一个 **struct bt\_driver\_s** 结构体类型的变量，并为其初始化以下成员函数：

  - <span class="reference">CODE int (\*open)(FAR struct bt\_driver\_s \*btdev)</span>
  - <span class="reference">CODE int (\*send)(FAR struct bt\_driver\_s \*btdev, enum bt\_buf\_type\_e type, FAR void \*data, size\_t len)</span>
  - <span class="reference">CODE int (\*ioctl)(FAR struct bt\_driver\_s \*btdev, int cmd, unsigned long arg)</span>
  - <span class="reference">CODE void (\*close)(FAR struct bt\_driver\_s \*btdev)</span>

这些成员函数的实现依赖于 HCI 的实际工作方式，也就是 Host 和 Controller 之间的物理总线。

### 注册驱动

实现上述结构体类型的变量后，需要通过 API <span class="reference">bt\_driver\_register\*\*()</span> 注册该驱动实例。

  - <span class="reference">int bt\_driver\_register\*\*(FAR struct bt\_driver\_s \*drv)</span>

类型定义可参考头文件 <span class="reference">nuttx/include/nuttx/wireless/bluetooth/bt\_driver.h</span>。调用关系如下图所示：

![img](https://vela-open-doc.cnbj1.mi-fds.com/vela-open-doc/1781005749662_bt_driver.png)

### 备注

对于 <span class="reference">receive()</span> 成员函数，芯片厂商无需定义，BTH4 驱动会为其初始化。

  - <span class="reference">CODE int (\*receive)(FAR struct bt\_driver\_s \*btdev, enum bt\_buf\_type\_e type, FAR void \*data, size\_t len)</span>

当收到来自芯片的 HCI 数据时，只要调用 <span class="reference">bt\_netdev\_receive()</span> 即可，它会调用这个 <span class="reference">receive()</span> 函数来保存收到 HCI 数据。

# 五、相关仓

  - [frameworks\_bluetooth](https://github.com/open-vela//docs/https:/github.com/open-vela/docs/frameworks_bluetooth)：该仓库旨在为应用程序开发者提供丰富的蓝牙应用编程接口，包括 API 接口层、各种 Service 服务组件层、SAL 协议栈适配层和 HAL 硬件适配层。此外，仓库还配备了 [bttool](https://doc.openvela.com/document?id=1548&version=dev-ai-contest-2026&language=cn) 等工具，一方面可直接用于用于测试蓝牙功能；另一方面可用于蓝牙应用编程时相关 API 的 Sample 参考代码。
  - [external\_zblue](https://github.com/open-vela//docs/https:/github.com/open-vela/docs/external_zblue)：该仓库源自于 Zephyr 社区，但 openvela 对很多功能进行了补充和增强。
  - [docs](https://github.com/open-vela//docs/https:/github.com/open-vela/docs/docs)：该仓库提供更多关于蓝牙模块的技术文档。
