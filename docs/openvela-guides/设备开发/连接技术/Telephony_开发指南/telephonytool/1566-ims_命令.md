# 一、概述

在 openvela 的 NSH 命令行中，可以通过 <span class="reference">telephonytool</span> 命令工具进入 Console，执行所有与 IMS（IP Multimedia Subsystem）相关的操作。

# 二、前提条件

打开 <span class="reference">telephonytool</span>，执行如下命令：  

    ap> telephonytool

# 三、命令

## 1、enable-ims

### 命令说明

<span class="reference">enable-ims</span> 命令用于开启或关闭 IMS（IP Multimedia Subsystem）能力。

### 命令格式

    enable-ims [slot_id][action]

  - slot\_id：设置要监听的卡槽，目前仅支持 <span class="reference">0</span>。
  - action：
      - <span class="reference">0</span>：关闭 IMS 能力。
      - <span class="reference">1</span>：开启 IMS 能力。

### 示例

##### 命令输入

    telephonytool>enable-ims 0 1

##### 输出信息

    telephonytool> enable-ims 0 1
    [149517.760100] [35] [ DEBUG] [ap] telephonytool_cmd_ims_enable: slot_id: 0, action: 1
    telephonytool> [149517.786400] [21] [  INFO] [ap] [0,0124]> RIL_REQUEST_IMS_REG_STATE_CHANGE (1)
    [149518.064500] [25] [  INFO] [ap] [AT_NETWORK] Receive signal strength URC

## 2、get-ims-enabled

### 命令说明

<span class="reference">get-ims-enabled</span> 命令用于获取 IMS（IP Multimedia Subsystem）开关的当前状态。

### 命令格式

    get-ims-enabled [slot_id]

  - slot\_id：设置要监听的卡槽，目前仅支持 <span class="reference">0</span>。

### 示例

##### 命令输入

    telephonytool>get-ims-enabled 0

##### 输出信息

    telephonytool> get-ims-enabled 0
    [149542.284600] [35] [ DEBUG] [ap] telephonytool_cmd_get_ims_enabled: slot_id: 0, ims enable: 1

## 3、set-ims-cap

### 命令说明

<span class="reference">set-ims-cap</span> 命令用于设置支持 IMS（IP Multimedia Subsystem）的业务功能。

### 命令格式

    set-ims-cap [slot_id][cap-value]

  - slot\_id：设置要监听的卡槽，目前仅支持 <span class="reference">0</span>。
  - cap-value：IMS 支持的功能类型：
      - <span class="reference">1</span>：语音（voice）。
      - <span class="reference">4</span>：短信（SMS）。
      - <span class="reference">5</span>：语音和短信（voice & SMS）。

### 示例

##### 命令输入

    telephonytool> set-ims-cap 0 1

## 4、listen-ims

### 命令说明

<span class="reference">listen-ims</span> 命令用于监听指定卡槽的 IMS（IP Multimedia Subsystem）注册状态，包含信号强度和网络状态变化等信息。

### 命令格式

    listen-ims [slot_id]

  - slot\_id：监听的卡槽 ID，目前仅支持 <span class="reference">0</span>。

### 示例

##### 命令输入

    telephonytool>listen-ims 0

##### 输出信息

    telephonytool> listen-ims 0
    [149573.889900] [35] [ DEBUG] [ap] telephonytool_cmd_ims_register: slot_id: 0, watch_id: 100

## 5、get-ims-registration

### 命令说明

<span class="reference">get-ims-registration</span> 命令用于查询 IMS（IP Multimedia Subsystem）相关信息，包括 IMS 注册状态和 VoLTE（Voice over LTE）状态。

### 命令格式

    get-ims-registration [slot_id][action]

  - slot\_id：设置要监听的卡槽，目前仅支持 <span class="reference">0</span>。
  - action：
      - <span class="reference">0</span>：表示查询 IMS 信息（IMS info）。
      - <span class="reference">1</span>：表示查询 IMS 注册状态（IMS state）。
      - <span class="reference">2</span>：表示查询 VoLTE 状态（VoLTE state）。

### 示例

##### 命令输入

    telephonytool>get-ims-registration 0 0

##### 输出信息

    telephonytool> get-ims-registration 0 0
    [149616.226900] [35] [ DEBUG] [ap] telephonytool_cmd_ims_get_registration: slot_id: 0, acton: 0
    [149616.229700] [35] [ DEBUG] [ap] telephonytool_cmd_ims_get_registration: ret_info: 0, ext_info: 0
