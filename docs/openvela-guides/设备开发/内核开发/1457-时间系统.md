# 一、概述

本文档提供了时间系统的概述，包括关键时间概念、时间类型、API 和管理时间及时区的命令。

# 二、前置概念

## 1、世界标准时间（UTC）

  - 定义：UTC 是全球统一的时间标准。
  - 与北京时间（CST）的关系：北京时间比 UTC 快 8 小时，即 UTC+8。

## 2、日历时间（Calendar Time）

  - 定义：日历时间是一种相对时间，用秒数表示从某个标准时间点到当前时刻的时间间隔。

  - 特点:
    
      - 统一性：无论在哪个时区，同一时刻的日历时间相对于同一标准时间点始终一致。
      - 标准时间点：通常以 UTC 时间 1970-01-01 00:00:00 为基准时间点（即 Unix 时间纪元）。
      - 表示方式：以秒数形式表示，常用于计算机系统中作为时间戳。

# 三、<span class="reference">localtime</span> 在 openvela 中的实现说明

## 两种实现方式

  - 打开 <span class="reference">CONFIG\_LIBC\_LOCALTIME</span>：
    
      - <span class="reference">localtime</span> 的实现依赖 <span class="reference">zoneinfo</span>，可以根据时区正确转换时间。
    
      - 优点：支持时区转换，功能更完善。
    
      - 缺点：会增加代码体积， **增加约 6.4KB**。
        
        ![img](https://vela-open-doc.cnbj1.mi-fds.com/vela-open-doc/1781005731838_001.png)

  - 未打开 <span class="reference">CONFIG\_LIBC\_LOCALTIME</span>：
    
      - <span class="reference">localtime</span> 和 <span class="reference">gmtime</span> 的效果相同，直接返回 UTC 时间，不进行时区转换。
      - 优点：节省空间，无额外开销。
      - 缺点：不支持时区转换。

# 四、设置时区

**<span class="reference">tzset</span> 函数**

从环境变量 <span class="reference">TZ</span> 获取时区信息，初始化以下内容：

  - <span class="reference">timezone</span> ：当前时区相对于 UTC 的偏移（以秒为单位）。
  - <span class="reference">daylight</span> ：是否启用夏令时（非零表示启用）。

## 1、TZ 环境变量格式

### 字符串格式

<span class="reference">TZ</span> 环境变量支持以下格式：  

    std offset[dst[offset][,start[/time],end[/time]]]

**参数说明**

1.  std
    
    表示时区缩写，由三个或三个以上的字符组成。例如：
    
      - CST：中国标准时间。
      - EST：东部标准时间。

2.  offset
    
      - 当前时区与 UTC 的偏移量。
      - 格式为 <span class="reference">±hh:mm:ss</span>，例如 <span class="reference">+8:00:00</span> 表示东八区（UTC+8）。

3.  dst（可选）
    
    表示夏令时时区缩写。

4.  offset（可选）
    
      - 夏令时相对于 UTC 的偏移量。
      - 如果省略，默认比标准时间提前 1 小时。

5.  start\[/time\]，end\[/time\]（可选）
    
    表示夏令时开始和结束规则：
    
      - 格式为 <span class="reference">M\<month\>.\<week\>.\<day\></span>：
        
          - <span class="reference">M10.1.0</span>：10 月的第一周的星期天。
          - <span class="reference">M3.3.0</span>：3 月的第三周的星期天。
    
      - <span class="reference">/time</span> 表示具体时间（可选）。

### 文件路径格式

<span class="reference">TZ</span> 环境变量支持通过文件路径指定时区信息，格式如下：

1.  路径格式。
    
      - <span class="reference">Asia/Shanghai</span>：相对路径，表示系统时区目录（由 <span class="reference">CONFIG\_LIBC\_TZDIR</span> 指定）下的文件。
      - <span class="reference">/Asia/Shanghai</span>：绝对路径，表示直接指定时区文件的完整路径。
      - <span class="reference">:Asia/Shanghai</span>：同时支持绝对路径和系统时区目录下的相对路径。

2.  解析规则：找到时区文件后，会根据 <span class="reference">tzfile</span> 格式解析文件内容，加载对应的时区信息。

## 2、<span class="reference">zoneinfo</span> 制作与挂载说明

### <span class="reference">zoneinfo</span> 制作流程

1.  <span class="reference">tzfile</span> 格式
    
    <span class="reference">zoneinfo</span> 使用 <span class="reference">tzfile</span> 格式存储时区信息，具体格式请参考 [tzfile文档](https://man7.org/linux/man-pages/man5/tzfile.5.html)。

2.  数据库下载。
    
    从 [时区数据库](https://www.iana.org/time-zones) 下载最新的时区数据。

3.  生成 <span class="reference">tzbin</span>目录。
    
    使用下载的时区数据，生成包含 <span class="reference">zoneinfo</span> 文件的 <span class="reference">tzbin</span> 目录，如下图所示：
    
    ![img](https://vela-open-doc.cnbj1.mi-fds.com/vela-open-doc/1781005731936_002.png)

4.  生成 <span class="reference">romfs</span> 文件。
    
      - 使用 Linux 工具 <span class="reference">genromfs</span> 将 <span class="reference">tzbin</span> 目录打包为 <span class="reference">romfs</span> 格式的镜像文件。
      - 该镜像文件可挂载到设备上，供程序使用。

### 在模拟器和板子上的挂载方式

##### 在模拟器（sim）中挂载

1.  创建 RAM 磁盘。  
    
        mkrd -m 10 -s 512 102400
    
      - <span class="reference">-m 10</span>：指定 RAM 设备号为 <span class="reference">/dev/ram10</span>。
      - <span class="reference">-s 512</span>：设置块大小为 512 字节。
      - <span class="reference">102400</span>：设置磁盘大小为 102400 个块。

2.  挂载 <span class="reference">hostfs</span> 文件系统。
    
    在当前路径下存放 <span class="reference">romfs.img</span> 文件，然后挂载：  
    
        mount -t hostfs fs=. /data

3.  将 <span class="reference">romfs.img</span> 写入 RAM 磁盘。  
    
        dd if=/data/romfs.img of=/dev/ram10

4.  挂载 <span class="reference">romfs</span> 文件系统。  
    
        mount -t romfs /dev/ram10

##### 在板子上挂载

1.  找到文件分区起始地址。
    
      - 使用下载工具，将 <span class="reference">romfs</span> 镜像文件烧录到对应的物理分区地址。

2.  挂载分区。
    
      - 挂载后即可使用时区文件。

### <span class="reference">zoneinfo</span> 制作工具

1.  自动生成。
    
      - 在 <span class="reference">libs/libc/zoneinfo/</span> 目录下的 <span class="reference">Makefile</span> 可自动下载时区数据库，并将其打包为 <span class="reference">romfs</span> 镜像文件，对应 <span class="reference">config</span> 如下：
        
        ![img](https://vela-open-doc.cnbj1.mi-fds.com/vela-open-doc/1781005732043_003.png)
    
      - 运行 <span class="reference">Makefile</span> 后，生成 <span class="reference">romfs\_zoneinfo.img</span> 文件。
        
        ![img](https://vela-open-doc.cnbj1.mi-fds.com/vela-open-doc/1781005732141_004.png)

2.  挂载生成的镜像文件。
    
    在模拟器中挂载：  
    
        mkrd -m 10 -s 512 800  
        dd if=data/romfs_zoneinfo.img of=/dev/ram10  
        mount -t romfs /dev/ram10 zoneinfo

### 指定时区文件位置

如果需要指定 <span class="reference">zoneinfo</span> 文件的位置，可以设置宏：  

    CONFIG_LIBC_TZDIR=/zoneinfo

## 3、设置时区的方法

### 通过启动脚本设置时区

在 <span class="reference">rcS</span> 启动脚本中设置环境变量（在调用 <span class="reference">tzset</span> 之后生效）：  

    # 设置为上海时区  
    set TZ Asia/Shanghai  
    
    # 中国标准时间（无夏令时）  
    set TZ CST+08:00:00  
    
    # 设置为奥克兰时区  
    set TZ :Pacific/Auckland  
    
    # 设置为查塔姆时区  
    set TZ :Pacific/Chatham  
    
    # 新西兰标准时和夏令时  
    set TZ "NZST-12:00:00NZDT-13:00:00,M10.1.0,M3.3.0"

### 动态设置时区

通过代码动态设置时区：

1.  调用 <span class="reference">setenv</span> ：设置环境变量 <span class="reference">TZ</span>。
    
    每个任务（<span class="reference">task</span>）都有独立的环境变量，因此可以持有不同的时区信息。

2.  调用 <span class="reference">tzset</span> ：同步时区信息。

### 命令行设置时区

使用命令行工具设置时区：  

    # 设置为东京时区  
    timedatectl set-timezone Asia/Tokyo

# 五、多核时区设置说明

在多核系统中，openvela 建议：

1.  **UI 显示的核**：负责设置时区信息，用于本地时间显示。
2.  **其他核**：始终使用 UTC 时间，避免设置时区。

**原因：**

  - 每个核的 <span class="reference">tzset</span> 是独立的，无法自动同步。
  - 如果需要要多个核保持相同的时区信息，需要在每个核上单独调用 <span class="reference">tzset</span>设置时区。

**建议：**

  - 除负责 UI 显示的核外，其他核尽量避免使用 <span class="reference">localtime</span>，统一使用 UTC 时间（即 <span class="reference">gmtime</span>）。
  - 多核系统中打印日志统一采用 UTC 时间，保持一致性。

**特殊情况：**

  - 如果多核需要访问 <span class="reference">zoneinfo</span> 文件：
      - 当资源存储在 eMMC 中，其他核需要通过 <span class="reference">rpmsgfs</span> 才能访问 <span class="reference">tzfile</span> 信息。

# 六、时间类型

**<span class="reference">time\_t</span>**

  - **描述**：存储从 1970 年 1 月 1 日 00:00:00 到现在经过的秒数。
  - **实现**：在 openvela 中，<span class="reference">time\_t</span> 实现为 <span class="reference">uint32\_t</span> 或 <span class="reference">int64\_t</span>。

**<span class="reference">struct timeval</span>**

  - 描述：提供秒和微秒单位，最高精度是微秒。

  - 结构：  
    
        struct timeval
        {
        time_t tv_sec; // 自 1970-01-01 00:00:00 起的秒数  
        long tv_usec;  // 微秒  
        };

**<span class="reference">struct timespec</span>**

  - 描述：提供秒和纳秒单位，最高精度是纳秒。

  - 结构：  
    
        struct timespec
        {
        time_t tv_sec;  
        long   tv_nsec; 
        };

**<span class="reference">stuct tm</span>**

  - 描述：提供详细的日期和时间信息。

  - 结构：  
    
        struct tm
        {
        int  tm_sec;         /* Seconds (0-61, allows for leap seconds) */
        int  tm_min;         /* Minutes (0-59) */
        int  tm_hour;        /* Hours (0-23) */
        int  tm_mday;        /* Day of the month (1-31) */
        int  tm_mon;         /* Month (0-11) */
        int  tm_year;        /* Years since 1900 */
        int  tm_wday;        /* Day of the week (0-6) */
        int  tm_yday;        /* Day of the year (0-365) */
        int  tm_isdst;       /* Non-0 if daylight savings time is in effect */
        long tm_gmtoff;      /* Offset from UTC in seconds */
        const char *tm_zone; /* Timezone abbreviation. */
        };

# 七、时间 API

## 1、常用时间 API

<span class="reference">time\_t time(FAR time\_t \*timep)</span>

  - 描述：获取或设置当前日历时间。

  - 参数：指向存储日历时间的指针。如果为 <span class="reference">NULL</span>，则函数返回当前日历时间。

  - 返回值：返回当前日历时间，类型为 <span class="reference">time\_t</span>。

  - 示例：  
    
        time_t current_time;  
        current_time = time(NULL); // 获取当前日历时间  
        printf("Current time: %ld\n", current_time);

<span class="reference">int clock\_gettime(clockid\_t clockid, FAR struct timespec \*tp)</span>

  - 描述：获取指定时钟的当前时间。

  - 参数：
    
      - <span class="reference">clockid</span>： 要获取时间的时钟。常见值：<span class="reference">CLOCK\_REALTIME</span>、<span class="reference">CLOCK\_MONOTONIC</span>。
    
      - <span class="reference">tp</span>： 指向 <span class="reference">struct timespec</span> 的指针，用于存储获取的时间。
    
      - 返回值：成功返回 <span class="reference">0</span>，失败返回 <span class="reference">-1</span>。
    
      - 示例：  
        
            struct timespec ts;  
            clock_gettime(CLOCK_REALTIME, &ts);  
            printf("Seconds: %ld, Nanoseconds: %ld\n", ts.tv_sec, ts.tv_nsec);

<span class="reference">int clock\_settime(clockid\_t clock\_id, FAR const struct timespec \*tp)</span>

  - 描述：设置指定时钟的时间。当 <span class="reference">clockid</span> 为 <span class="reference">CLOCK\_REALTIME</span> 时，用于设置 UTC 时间。

<span class="reference">int clock\_getres(clockid\_t clk\_id, struct timespec \*res)</span>

  - 描述：用于获取时钟精度，最高精度是纳秒。

## 2、时间转换 API

1.  <span class="reference">time\_t timegm(FAR struct tm \*tmp)</span>
    
      - 描述：将 <span class="reference">struct tm</span> 转换为从 <span class="reference">1970-01-01 00:00:00</span> 至今的秒数（UTC 时间）。

2.  <span class="reference">FAR struct tm \*gmtime(FAR const time\_t \*timep)</span>
    
      - 描述：将从 <span class="reference">1970-01-01 00:00:00</span> 至今的秒数转换为 <span class="reference">struct tm</span> 格式的时间，并用 UTC 时间表示。
    
      - 说明：<span class="reference">gmtime\_r</span> 是线程安全版本。

3.  <span class="reference">time\_t mktime(FAR struct tm \*tp)</span>
    
    描述：将 <span class="reference">struct tm</span> 转换为依据本地时区的秒数。

4.  <span class="reference">FAR struct tm \*localtime(FAR const time\_t \*timep)</span>
    
      - 描述：将从 <span class="reference">1970-01-01 00:00:00</span> 至今的秒数转换为 <span class="reference">struct tm</span> 格式的时间，并用本地时区表示。
      - 说明：<span class="reference">localtime\_r</span> 是线程安全版本。

5.  <span class="reference">FAR char \*asctime(FAR const struct tm \*tp)</span>
    
      - 描述：将日期和时间格式化为字符串并返回。
      - 说明：<span class="reference">asctime\_r</span> 是线程安全版本。

6.  <span class="reference">size\_t strftime(FAR char \*s, size\_t max, FAR const char \*format, FAR const struct tm \*tm)</span>
    
      - 描述：将 <span class="reference">struct tm</span> 中的数据按照 <span class="reference">format</span> 的格式填充到字符串 <span class="reference">s</span> 中，长度最长为 <span class="reference">max</span>。

7.  <span class="reference">FAR char \*strptime(FAR const char \*s, FAR const char \*format, FAR struct tm \*tm)</span>
    
    描述：将字符串 <span class="reference">s</span> 按照 <span class="reference">format</span> 的格式解析，并初始化 <span class="reference">struct tm</span> 结构体。

8.  <span class="reference">FAR char \*ctime(FAR const time\_t \*timep)</span>
    
      - 描述：返回一个表示当地时间（<span class="reference">localtime</span>）的字符串。
      - 说明：<span class="reference">ctime\_r</span> 是线程安全版本。

9.  <span class="reference">double difftime(time\_t time2, time\_t time1)</span>
    
    描述：返回两次时间的差值，单位为秒。

## 3、高精度时间 API

1.  <span class="reference">int gettimeofday(FAR struct timeval \*tv, FAR struct timezone \*tz)</span>
    
      - **描述**：返回当前时间，包含自 <span class="reference">1970-01-01 00:00:00</span> 起的秒数和微秒数。
    
      - **参数**
        
          - <span class="reference">tv</span>：指向 <span class="reference">struct timeval</span> 的指针，用于存储秒数和微秒数。
          - <span class="reference">tz</span>：时区信息，通常传入 <span class="reference">NULL</span>。
    
      - **示例**：  
        
            struct timeval tv;  
            gettimeofday(&tv, NULL);  
            printf("Seconds: %ld, Microseconds: %ld\n", tv.tv_sec, tv.tv_usec);

2.  <span class="reference">int settimeofday(FAR const struct timeval \*tv, FAR struct timezone \*tz)</span>
    
    描述：设置系统时间（UTC）。

3.  <span class="reference">int clock\_systime\_timespec(FAR struct timespec \*ts)</span>
    
    描述：获取系统的运行时间（内核版 API）。

# 八、命令说明

## 1、查看系统运行时间

    ap> uptime
    14:11:37 up 3 days, 16:49, load average: 0.07, 0.07, 0.07

## 2、设置时区

    ap> timedatectl set-timezone Asia/Tokyo

## 3、设置时间

    ap> date -s "May 11 11:11:21 2022"

## 4、查看本地时间

默认显示 localtime，无时区时显示 UTC。  

    ap> date
    Wed, Oct 22 14:11:54 2104

## 5、查看 UTC 时间

    ap> date -u
    Wed, Oct 22 14:13:21 2104

## 6、查看时间和时区信息

    ap> timedatectl
          TimeZone: CST, 28800
        Local time: Mon, Oct 17 16:23:46 2022 CST
     Universal time: Mon, Oct 17 08:23:46 2022 UTC
          RTC time: Mon, Oct 17 08:23:47 2022
