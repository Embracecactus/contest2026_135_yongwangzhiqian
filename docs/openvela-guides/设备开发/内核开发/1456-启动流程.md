# 一、板级初始化流程

openvela 系统的启动过程遵循明确的板级支持包（BSP）初始化序列。该序列从内核入口 <span class="reference">nx\_start</span> 开始，在不同任务上下文中分阶段执行初始化函数，直至进入 <span class="reference">idle</span> 循环。

## 核心初始化顺序

    // --- 在 Idle Task (空闲任务) 上下文中 ---
    nx_start()
      |
      +--> board_early_initialize()
      |
      +--> // 创建 AppBringup_task 线程
    // --- 在 AppBringup_task (应用启动任务) 上下文中 ---
    board_late_initialize()
      |
      +--> // 创建 nsh_task 线程
    // --- 在 nsh_task (Nsh 任务) 上下文中 ---
    board_app_initialize()
      |
      +--> rc.sysinit // 执行脚本
      |
      +--> board_app_finalinitialize()
      |
      +--> rcS        // 执行脚本
    // --- 系统进入 idle 循环 ---

# 二、启动脚本机制

## 启动脚本位置与加载方式

openvela 使用启动脚本 <span class="reference">rcS</span> 和 <span class="reference">rc.sysinit</span> 来完成系统启动配置。启动脚本由 <span class="reference">nsh task</span> 通过 <span class="reference">nshlib</span> 加载并解析，其位置由以下配置项指定：

1.  <span class="reference">CONFIG\_ETC\_ROMFSMOUNTPT/CONFIG\_NSH\_SYSINITSCRIPT</span>
2.  <span class="reference">CONFIG\_ETC\_ROMFSMOUNTPT/CONFIG\_NSH\_INITSCRIPT</span>

通常，启动脚本存放于 <span class="reference">/etc</span> 目录下。<span class="reference">/etc</span> 的内容以 <span class="reference">romfs</span> 文件系统形式与 <span class="reference">openvela binary</span> 一同编译链接，系统启动后自动挂载。相关配置如下  

    CONFIG_FS_ROMFS=y
    CONFIG_ETC_ROMFS=y
    CONFIG_ETC_ROMFSMOUNTPT="/etc"
    CONFIG_NSH_SYSINITSCRIPT="init.d/rc.sysinit"
    CONFIG_NSH_INITSCRIPT="init.d/rcS"

## 启动脚本生成方式

openvela 的 <span class="reference">/etc</span> 内容由不同的板级目录生成，可通过 <span class="reference">genromfs</span> 和 <span class="reference">xxd</span> 工具生成 <span class="reference">etc\_romfs.c</span> 文件，并编译到内核。例如：

  - 生成文件路径: <span class="reference">boards/arm/at32/at32f437-mini/src/etc\_romfs.c</span>
  - 生成脚本路径: <span class="reference">boards/arm/at32/at32f437-mini/tool/mkromfs.sh</span>

常见方式是直接从 <span class="reference">board/arch/board/src/etc</span> 目录构建 <span class="reference">/etc</span> 内容。例如：

  - 示例目录: <span class="reference">boards/sim/sim/sim/src/etc</span>

<span class="reference">/etc</span> 下的所有文件由上一级目录的 Makefile 控制：

  - <span class="reference">RCSRCS</span> 用于指定启动脚本。

  - <span class="reference">RCRAWS</span> 用于指定加入 <span class="reference">etc</span> 目录下的其他文件和目录。  
    
        ifeq ($(CONFIG_ETC_ROMFS),y)
          RCSRCS = etc/init.d/rc.sysinit etc/init.d/rcS
          RCRAWS = etc/group etc/passwd
        endif
