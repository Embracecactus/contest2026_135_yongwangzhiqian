# BK7258 hardware references

本目录保存板级适配和硬件验证所使用的原理图证据。芯片实现依据仍固定为官方 BK7258 SDK v3.1.1.9；原理图只用于确认具体开发板的连线、极性和可验证能力。

## 已归档板型

- [`t5ai-core/`](t5ai-core/README.md)：T5AI Core V1.0.1 的硬件连接、原理图、
  板级验证和最小裸机探针。

T5 Board 和 AIDK AI Toy 的板型资料准备完成后，应各自新建同级目录；不能把
T5AI Core 的引脚、串口或探针结论推广到另外两块板。

原始文件由项目维护者提供。仓库副本必须保持原样；若文件被替换，应同步更新硬件连接文档中的 SHA256 和审阅结论。
