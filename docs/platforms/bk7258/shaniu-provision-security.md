# 傻妞认领、BLE 控制与配网安全合同

本文件定义傻妞产品路径中设备认领、手机管理连接和受保护配置的稳定安全边界；
它不是实施计划、退出门或验收状态表。当前功能、配置选择和验证边界分别以
[功能与证据清单](shaniu-feature-inventory.md)、
[板级配置](../../../boards/bk7258/CONFIGS.md) 和
[Android 操作说明](../../../android/shaniu-companion/README.md) 为准。

[Git 固定基线中的历史版本](https://github.com/open-vela/contest2026_135_yongwangzhiqian/blob/e4f2df717defab9f6ad02adc662acd8cba086cf2/docs/platforms/bk7258/shaniu-provision-security.md)。

## 身份、认领与所有权

- 设备发现、BLE 地址、显示名称或广播内容都不能证明设备身份或所有权。未认领设备
  由屏幕上的认领码引导手机建立连接；手机在发送受保护内容前核对该认领信息与设备
  证书。操作入口和恢复边界见[上手指南](shaniu-user-guide.md#A-开箱与手机认领)。
- 初次认领只能发生在设备允许的未认领窗口内。已认领设备不接受普通扫描或重复认领
  来覆盖现有 owner；结果不确定时只能查询认领结果，不能重放提交。
- 手机的本地认领资料属于该手机的安全存储。卸载 App、清除 App 数据或换手机可能
  使资料不可用，但不构成重新取得设备所有权的权限。转交、恢复和本机连接资料移除
  的产品语义以 App 的“认领与设备身份”说明为准。
- 设备身份、手机 owner 凭据、Wi-Fi/云服务配置和固件签名根相互独立。拥有其中一项
  不自动授予其余能力。

## 传输与会话边界

- BLE GATT 只承载认证 TLS 会话的密文字节；不得新增明文 Wi-Fi 密码、云服务 Key、
  owner 凭据或控制命令的特征值协议，也不得把调试 ECHO/BURST 服务当作产品认领服务。
- 手机必须验证设备证书及其预期身份；不得使用 trust-all、仅凭设备名称或地址接受
  新设备，也不得在认证失败后降级为明文连接。
- 一次控制会话绑定一次实际连接和其认证状态。断连、取消、超时、代际变化或认证失败
  都会使该会话失效；后续操作必须重新连接和认证，旧回调、旧请求或旧回执不能取得
  新连接的控制权。
- 协议处理保持有界和串行：传输分片、背压与连接回调不能在 BLE 回调线程中执行
  阻塞的 TLS、文件或网络操作。具体帧格式、大小和时限是实现细节，不在本文冻结；
  改动时须由协议源码和相应主机测试共同更新。

## 配置、凭据与提交

- 认证完成也不等于配置已经生效。网络、云服务和设备偏好通过受保护的控制会话提交，
  设备以明确回执区分已提交、未提交与未知结果；未知结果应走只读核对路径，不能盲目
  重发包含秘密的配置。
- Wi-Fi 密码、云服务 Key 和设备私钥不得出现在 App 日志、固件日志、二维码截图、
  测试报告或公开仓库。配置读取只返回允许公开的状态和非秘密字段；密码与 Key 不回读。
- 提交必须保持完整性：失败、断连或重启不得把半套网络/云服务配置当作可用配置，也
  不得因无法读取配置而把设备误判为未认领。旧 owner 配置或凭据的撤销遵循产品的
  转交/恢复流程。
- 手机只把管理所需的本地凭据保存到 Android 安全存储；不把设备私钥或完整云服务
  秘密复制到普通偏好存储。设备端数据保护与启动镜像信任是不同层次：已签名固件不
  等同于承诺抗物理提取或安全元件保护。

## 权限与恢复

- 管理、OTA、电脑授权和资源作业均要求当前 owner 的受认证控制会话及其各自授权，
  不能借认领二维码、历史连接或其他手机的资料绕过。
- 恢复操作应关闭现有会话并撤销旧控制资料；它不应在不确定结果下自动清除手机端
  记录。实际恢复、认领和配网的用户步骤与限制见
  [Android 操作说明](../../../android/shaniu-companion/README.md#认领与设备身份)。
- 工厂烧录、设备身份供应和签名发布不是日常认领流程。需要这些操作时，使用
  [`tools/bk7258/README.md`](../../../tools/bk7258/README.md) 与
  [构建、发布与硬件证据 SOP](nuttx-port/bk7258-build-flash-debug-sop.md)，不要从
  旧认领文档复用手工凭据、证书或串口步骤。

## 证据与变更要求

本合同只描述安全设计约束，不把源码、构建、模拟器、手机或实板检查混为一项结论。
认领、配网、会话恢复和权限拒绝的当前证据及未验证边界见
[功能与证据清单](shaniu-feature-inventory.md)；每次修改认证、所有权、持久化或控制
协议时，至少更新受影响的主机回归，并按变更风险补充手机与实板验证。不得用构建成功
替代真实设备上的身份、凭据或恢复验证。
