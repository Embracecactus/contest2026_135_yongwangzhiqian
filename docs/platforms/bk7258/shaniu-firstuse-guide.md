# 傻妞普通用户首次使用指南

适用：已由工厂正式部署（或已重新工厂初始化）的傻妞。**全程不需要电脑、串口、
openssl，也不需要任何证书/私钥/授权 JSON 文件。**

## 1. 开机

1. 给傻妞通电。首次启动需要十几秒：设备会自行完成受控首启初始化、生成本机
   唯一身份，然后在一块圆屏上显示认领二维码，另一块显示“用手机扫我”的提示。
2. 二维码里是本次认领窗口的定位信息、设备证书完整指纹和一次性窗口秘密；
   窗口超时后二维码会失效，重新开窗会生成新的秘密（旧截图不能再用）。

## 2. 手机认领（可离线）

1. 安装 `shaniu-companion` APK（`0.5.24-shaniu-firstuse` 或更高）。
2. 打开 App → **添加我的傻妞** → **扫码添加傻妞** → 对准傻妞屏幕上的二维码。
3. App 会用扫码得到的指纹校验 BLE 上的设备身份（TLS 双向固定指纹），再用
   窗口秘密完成持有证明。此步**不需要互联网**：手机可以只开蓝牙。
4. 认领成功后，App 保存该设备的控制凭据（Android Keystore）。

## 3. 设置 Wi-Fi 与语音服务

1. 认领成功后 App 直接进入 Wi-Fi 页：填 Wi-Fi 名称与密码（或让傻妞扫描附近
   网络）。可以打开傻妞的热点，也可以让手机与傻妞在同一局域网。
2. 选语音服务：MiMo Token Plan（订阅）/ MiMo 标准接口 / 其他兼容服务；
   自己填 API Key（作者不内置任何密钥，仓库与 APK 都不含）。
3. 点“保存并连接”。设置经**已认证蓝牙通道**提交，设备保存成功后回读确认。
   设备回到首页即表示配置已写入。

## 4. 首次对话

喊唤醒词（默认「你好，openvela」，也可在 App 里换成「你好冰冰」「你好傻妞」）。
听到应答后正常对话即可。

## 5. 日常与故障

- **重启**：直接断电再上电。身份、owner、Wi-Fi 与云配置、眼睛资源都会保留，
  热点/网络会自行恢复。
- **换 Wi-Fi / 换模型**：打开 App → 设备配置，改完保存即可；不需要重新认领，
  也不需要电脑。
- **没有 Wi-Fi 时**：设备仍是“已认领”的可管理状态，蓝牙设置入口可用；
  本地唤醒与应答不依赖网络，云端对话会明确提示未配置。
- **换手机**：需要在原手机上解除绑定，或用原手机的认领资料重新认领；
  设备不会因为“读不到身份”就重新生成一个新身份。
- **二维码失效/认领到一半断了**：重新让设备显示二维码再扫一次；App 会先核对
  上次提交的真实结果，不会重复认领。
- **恢复出厂**：本轮设备侧入口尚未实现（见生命周期文档 §4）。

## 6. 兼容入口（维修/旧设备）

旧版设备由厂家提供的 `owner-bootstrap.json` 仍可在 App 开发者入口导入使用；
它只用于兼容与维修，不是新设备主路径。
