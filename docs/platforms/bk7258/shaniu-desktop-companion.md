# 傻妞桌面伙伴行为合同

本合同约束动作、有限触觉及其与现有产品服务的连接。实板、版本和
阶段状态以平台入口及本轮验收记录为准，不用注入轨迹表示真人准确率。

## N1 输入与反馈

- 唯一 motion worker 受产品准入控制，采样间隔至少 100 ms；关闭后无自主采样。
  查询只复制一个快照；设备 I/O 仍由 motion 服务串行执行。样本来源为
  AP uORB sensor_accel，时间为该 AP 单调微秒；旧/重复/未来及超过
  250 ms 的样本不产生反馈，间隔超过 250 ms 后重新建立参考。
- 复用动作候选判定：相邻变化 3000 mm/s² 进入移动，稳定区
  500 mm/s²、驻留 400 ms，重力有效区 8000–12000 mm/s²，倾斜
  进入/退出余弦 0.80/0.95。事件冷却 2 s。这是初始行为合同，
  不是拿起/放下、绝对位置或真人手势调参结论。
- 移动、稳定、倾斜只发布最长 800 ms 的缓存表情意图，不读 SD、
  不装包、不持久化默认。认领、电源、显式资源/表情操作、语音、专注
  和任务界面优先；被抢占事件直接作废，恢复当前资源缓存，不补播。
- 专注/任务完成沿同一产品事件路径请求 40 ms 脉冲，2 s 冷却，
  无排队重试。动作本身不振动，避免形成加速度反馈循环。触觉后
  500 ms 丢弃动作参考；说话及收音期间不触发，板级 capture_quiet
  仍是最后保护。OTA、电源关键阶段、健康样本无效/过期、电压
  ≤3400 mV 和电机故障抑制触觉。3400 mV 只是本功能保守抑制线，
  不用于关机、SOC 百分比或续航推断。
- 电机保持现有 GPIO 电平与共享供电投票，不引入 PWM/占空比；
  沿用板级最大 100 ms 和最短停机 1000 ms。退出取消待发脉冲并停止。
- 云凭据和 owner 不属于自主动作准入条件；认领 QR 仍优先显示。
  完成反馈只来自生产服务的实际完成，未知状态保持未知。

## N1 资源预算与证据边界

- 不增加线程、计时器、采集器、播放器或渲染器；沿用 motion、
  haptic、display worker 和产品事件循环。
- motion 新增一个 64 B 快照及有限元数据；产品策略状态预算
  256 B，显示意图元数据预算 64 B。不新增全帧缓存。
- 队列各一个合并槽；产品回调仅元数据操作，不等待传感器/SD/LCD。
  自主采样上限 10 Hz，显示沿既有 100 ms worker 节拍，SD 写入为零。
- 实际常驻/峰值内存、栈与设备 I/O 阻塞时间随候选构建/实板测量；
  未测值不写作实测保证。主机轨迹、真实采样、LCD 提交、驱动返回和
  真人视觉/体感分别验收。

## N2 场景与本地内容

- 复用 MFRC522 现有单卡选择及 500 ms NFC worker。仅现有驱动支持的
  ISO14443A UID 卡作为映射输入；HCE/ISO-DEP 是另一个已有协议，不意味着任意
  NFC 标签/手机兼容。未知、多卡冲突和读取失败不推断移开；可信移开才重新准入。
- 8 个映射槽，NCB1 旧专注时长可读，NCB2 用保留字节显式存 action；1–4 为
  原专注开始/暂停/继续/取消，5 为指定内容播放，6 为取消内容。内容参数仅支持
  ID 1。UID 不成为 owner，也不表达安装、清空设备或任意路径。
- NCF1 保留旧开始专注入口，NCF2 第 12 字节起为 action；NCS2 共 176 B，
  48 B 作业头后每槽 action:u32、reserved:u32、argument:u64，均大端。
  原 owner 认证、版本比较、操作身份、提交边界和取消语义保持。
- NCA2 为 48 B 查询：前 16 B 能力/服务状态；后续为 event:u64、action:u32、
  intent:u32、phase:u32、result:i32、reserved:u64。phase 0/1/2/3/4/5 分别为
  无结果/待执行/实际应用或内容结束/失败/取消/未知。意图受理不等于执行完成。
- 原生 App 设置中的“场景卡片”选择操作、登记、读回；旧固件仍限开始专注。
  一次仅放一张卡，登记后移开再碰卡；驻留不重播。页面关闭不替设备取消。
- 内容 ID 1 为原创四秒“四拍节律”，16 kHz、单声道 PCM16，128000 B；
  只从只读 ROMFS 读取，先验大小/SHA256，再由正式 Media 播放器执行。
  不触及 SD 可写卷，不与 MSC 争写，不替换“我在”。缺失/损坏明确失败。
- 产品 owner 暂停同一 KWS recorder，保留模型和配置；原 outbound worker 播放，
  完成/取消后恢复。语音交互、OTA、电源和 owner 失效优先，未准入不排队重试。
  队列为一个意图，待发最长 2 s，运行预算 8 s，排空最多 2 s；实际 Media
  I/O 及退出耗时仍需测量，不把预算称为硬实时保证。
- 资源预算：ROMFS +128000 B；PCM scratch 640 B，加一个 SHA256 context；
  固定元数据与 8 槽 action 扩展，无新常驻线程、全文件缓存、SD 写入或计时器。
  关闭失败保留清理错误并禁止新播放；电源/重置须等原 Media 清理完成。
