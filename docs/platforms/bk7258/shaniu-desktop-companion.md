# 傻妞桌面伙伴行为合同

本合同约束动作、有限触觉及其与现有产品服务的连接。实板、版本和
阶段状态以平台入口及本轮验收记录为准，不用注入轨迹表示真人准确率。

## N1 输入与反馈

- 唯一 motion worker 受产品准入控制，采样间隔至少 100 ms；关闭后无自主采样。
  连续准入期间由同一服务保留唯一 sensor 描述符，避免每轮重做激活/配置/关闭。
  失去准入只撤销快照并唤醒原 worker；worker 关闭描述符后才允许静默退出。
  关闭失败保持清理错误，禁止重新采样；取消后重入不能发布旧样本。
  查询只复制一个快照；设备 I/O 仍由 motion 服务串行执行。样本来源为
  AP uORB sensor_accel，时间为该 AP 单调微秒；旧/重复/未来及超过
  250 ms 的样本不产生反馈，间隔超过 250 ms 后重新建立参考。
- 复用动作候选判定：相邻变化 3000 mm/s² 进入移动，稳定区
  500 mm/s²、驻留 400 ms，重力有效区 8000–12000 mm/s²，倾斜
  进入/退出余弦 0.80/0.95。事件冷却 2 s。这是初始行为合同，
  不是拿起/放下、绝对位置或真人手势调参结论。
- 移动、稳定、倾斜只发布最长 800 ms 的缓存表情意图，不读 SD、
  不装包、不持久化默认。认领、电源、显式资源/表情操作、语音、专注
  和任务界面优先；被抢占事件直接作废，恢复当前资源缓存，不补播。
- 专注/任务完成沿同一产品事件路径请求 40 ms 脉冲，2 s 冷却，
  无排队重试。动作本身不振动，避免形成加速度反馈循环。触觉后
  500 ms 丢弃动作参考；说话及收音期间不触发，板级 capture_quiet
  仍是最后保护。OTA、电源关键阶段、健康样本无效/过期、电压
  ≤3400 mV 和电机故障抑制触觉。3400 mV 只是本功能保守抑制线，
  不用于关机、SOC 百分比或续航推断。
- 电机保持现有 GPIO 电平与共享供电投票，不引入 PWM/占空比；
  沿用板级最大 100 ms 和最短停机 1000 ms。退出取消待发脉冲并停止。
- 云凭据和 owner 不属于自主动作准入条件；认领 QR 仍优先显示。
  完成反馈只来自生产服务的实际完成，未知状态保持未知。

## N1 资源预算与证据边界

- 不增加线程、计时器、采集器、播放器或渲染器；沿用 motion、
  haptic、display worker 和产品事件循环。
- motion 新增一个 64 B 快照及有限元数据；产品策略状态预算
  256 B，显示意图元数据预算 64 B。不新增全帧缓存。分段计时元数据
  两份各 20 B，加两个租约布尔量；准入时保留一个原有 sensor 订阅描述符，
  不把该文件/uORB 分配的运行时成本算作零。
- 队列各一个合并槽；产品回调仅元数据操作，不等待传感器/SD/LCD。
  自主采样上限 10 Hz，显示沿既有 100 ms worker 节拍，SD 写入为零。
- 实际常驻/峰值内存、栈与设备 I/O 阻塞时间随候选构建/实板测量；
  未测值不写作实测保证。主机轨迹、真实采样、LCD 提交、驱动返回和
  真人视觉/体感分别验收。
