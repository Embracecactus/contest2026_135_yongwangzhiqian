# 文档 2:模型架构 — ~1M 参数非自回归声学模型逐层参数/算力表

非自回归(FastSpeech-lite 风)声学模型,专为 **<2M 参数、INT8 友好、全卷积 + 轻 Transformer、无自回归循环** 设计,便于在 bk7258 上用 TFLM + CMSIS-NN 推理。

## 1. 结构表

| 模块 | 层数 | 配置 | 参数量 | 说明 |
|---|---|---|---|---|
| Embedding | 1 | 60 音素 × 128 | 7.7K | 中文音素含声调 |
| Encoder Conv | ×6 | Conv1d(128,128,k=3) + ReLU + LN | 6×49K = 295K | 局部上下文 |
| Transformer Enc | ×4 | d=128, head=4, ffn=256 | 4×130K = 520K | 自注意力 |
| Duration Pred | 3×Conv + Linear | 128 → 1 | 147K | 预测音素时长 |
| Decoder Conv | ×6 | Conv1d(128,128,k=3) | 295K | 还原细节 |
| Output Linear | 1 | 128 → 80 (mel) | 10.4K | 80 维 mel |
| **合计** | | | **≈ 1.28M** | 落在 <2M 目标 |

- **mel 配置**:80 维,frame shift 12.5ms(80Hz);5 秒音频 ≈ 400 帧。
- **声码器**:Griffin-Lim(零参数,kissfft 做 ISTFT),不计入模型参数,板上纯 CPU/FFT。

## 2. 逐层算力估算(MAC / 推理)

非自回归:卷积/注意力在每帧上复用权重。

```
单句 MAC ≈ 2 × 参数量 × 输出帧数      (乘、加各算 1)
         = 2 × 1.28e6 × 400
         ≈ 1.02e9 MA+C / 5s
         ≈ 0.2 GOPS
```

- 与「方案 A 可行性深拆」用 sanoTTS 实测反推的 ~0.04–0.2 GOPS **吻合**。
- bk7258 保守 1 GOPS ⇒ 余量 ~5×;即便仅 30% 有效利用率仍实时。

## 3. 内存(INT8)

- **权重**:1.28M × 1 Byte ≈ **1.3 MB**(放 PSRAM / Flash,推理时按需搬)。
- **激活峰值**:逐层流式,单帧 128 维 + 中间特征,峰值 < 数百 KB,**可压在 640KB SRAM 内**。
- **工程要点**:用 TFLM Arena **逐层分配、用完即弃**,禁止全量驻留;此为方案 A 主要工程风险点(非算力)。

## 4. 输入/输出约定

- 输入:音素序列(拼音 + 声调),经 Embedding 入模型;
- 输出:80 维 mel 谱,帧率 80Hz;
- 时长预测(duration)可在板端 CPU 预处理完成,再以上采样结果喂入 TFLM 核心(见文档 3 算子覆盖说明)。
