## 3. 初赛后主要更新（表单可直接使用）

初赛后，我们把傻妞从“可连续对话的 AI 伴侣”扩展为桌面协作平台，并把每项能力的
验证范围分开说明：

1. **桌面交互延伸**：电脑任务由电脑执行、傻妞反馈，可选手机单次审批；电脑按需取景、
   保存当前画面、取消后重拍；动作采样与专注完成触觉反馈；NFC 场景卡登记与回读。
2. **可扩展与可维护**：签名原生小功能 ABI 3（启动 / 定时 / 存档，权限与执行预算受约束）；
   事实记忆可新增、纠正、删除，内置 Skill 可单独启停；Android 伙伴 App 重构为
   设备 / 定制 / 更新 / 设置四页。
3. **平台与语音链路**：唤醒模型多轮训练与审计；语音时延分轮埋点，主要等待定位到网络
   字节到达，同条件小样本对比后保留 MiMo 流式 TTS；Wi-Fi CSI 原始采集打通（研究阶段）。
4. **验证**：345 个不同 Android 主机用例通过（多次运行并集），14 组模拟器场景通过
   （含 11 个配网异常场景）；11-03 实板复测电脑任务成功 / 超时、审批过期、两帧
   640×480 取景及保存 / 取消 / 重拍。11-04 固件 `0.7.129+775` 实板确认**等待手机批准时**
   双眼显示感叹号、批准后清除，终端回执 `approved` / `authenticated=true` / 返回 0。

**尚未闭环**：实卡触发、触觉实际振感、手机拒绝、新版 OTA 重连、原生
小功能真机安装（发布公钥指纹待配置），以及长稳、多人唤醒和功耗。11-03 实板完整
CP/AP 版本未读回，不归为任一历史构建。
