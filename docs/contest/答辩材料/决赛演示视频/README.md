## 重新生成

在本目录使用已安装的 Python、Pillow、FFmpeg、剪映 Skill：

```bash
python3 build.py prepare --videos /path/to/videos
python3 build.py render --videos /path/to/videos
python3 build.py draft --videos /path/to/videos
python3 build.py verify --videos /path/to/videos
```

`prepare` 会复用已经存在的两个音视频兼容副本；如果更换对应原片，应先移除本目录相应的 `*-normalized.mp4` 再运行。`draft` 会更新本轮同名草稿；如已在剪映手动续剪，应先另存草稿或在剪辑表中更换工程名。

已完成媒体格式与时长检查、整片解码（零错误）、16 个时间点的关键帧检查、音量测量和剪映草稿媒体引用检查。成片综合响度 −16.08 LUFS，真峰值 −1.99 dBTP；计算器打开、工作台采图结果均在最终成片中确认。结果见 `verification/review.json`、`verification/draft-check.json` 和 `delivery.json`。没有进行全片人工试听或剪映界面播放验收。

已清理本轮可重建的分段编码缓存，保留原片、草稿依赖资产和一份最终成片；需要重做时运行上述生成命令即可。
