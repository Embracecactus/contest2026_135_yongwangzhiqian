# PPT 与 4K 合集素材

本目录保留照片、封面、眼睛素材和 `实拍/clips.json`，MP4 原片/切片留在本地。
实拍清单中的 `source_path` 和 `audio_source` 以 `cut_clips.py --videos` 指定的目录为根；手机原片以 `--source-dir` 为根。

PPT 和 4K 合集沿用 MiSans Medium。请从小米官方字体发行包安装，并将 `MiSans-Medium.ttf` 放入 `fonts/`；本次归集不重新分发该字体。历史成片所用文件的 SHA-256 记录在上级 `delivery.json`。不要用字体替换后新渲染的结果声称与历史成片逐帧相同。

《我在》使用另一套已随工程提供的 Noto Sans SC 和霞鹜文楷，附有 OFL 许可，与这里的本地 MiSans 输入无关。
