# BK7258 platform-v2 P2 SDK registry verification

- Date: 2026-08-15
- Branch: `refactor/bk7258-platform-v2`
- Scope: metadata-only SDK registry/set/lock and host verification commands.

## Implemented

- `board/bk7258/scripts/bk7258_sdk_schema.json` declares the versioned strict
  metadata contract.  Registry entries use `sha256:<manifest-digest>` IDs and
  distinguish `official`, `derived` and `sealed-binary` provenance.
- `bk7258_sdk_registry.json` binds the tracked role manifests/provenance files;
  AP records with `source_archive=not-provided` are explicitly not
  source-reproducible.  The private mirror URL is metadata-only and
  `redistribution_authorized=false`; no SDK bytes are present.
- `bk7258_sdk_set.json` selects the current T5AI-Core CP/AP pair.  The lock
  binds registry/set file digests and records BL2 as `no-runtime-sdk`.
- `sdk-verify` validates metadata and, when given `--bundle ROLE=PATH`, scans
  the external bundle for exact manifest paths and hashes.  `sdk-import` only
  emits a new receipt after verification and refuses existing output paths;
  `--replace` is not an accepted option.

requires an owner-provided external SDK directory and is intentionally not a
claim of source reproducibility for sealed AP artifacts.
