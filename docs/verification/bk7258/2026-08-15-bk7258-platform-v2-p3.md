# BK7258 platform-v2 P3 config and isolated build-plan verification

- Date: 2026-08-15
- Branch: `refactor/bk7258-platform-v2`
- Scope: product/mode config generation and metadata-only BL1/BL2/CP/AP plan.

## Implemented

- `bk7258_build_plan_schema.json` and the resolver validators define strict,
  versioned config/plan documents.  Config output embeds product, mode, board,
  role, IR identity, canonical symbols and defconfig digest.
- `build-plan` resolves CP/AP/BL2 together from exactly one product board and
  adds BL1.  Every role has a distinct source-view ID, build root, artifact
  root and `.config` path template; source roots remain existing read-only
  repository paths.
- CP/AP plan SDK rows bind to the P2 lock.  BL1/BL2 have `sdk=null`; BL2 names
  the existing minimal Makefile and `fake_nuttx_seed=false`.  The legacy dual
  builder is recorded as compatibility-only and is not invoked.
