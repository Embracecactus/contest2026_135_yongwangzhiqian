# BK7258 AP peripheral wrapper compile verification

Date: 2026-08-08

## Scope

Board-owned wrappers imported from the CodeBuddy worktrees were reviewed
against the NuttX lower-half APIs and the immutable official SDK v3.1.1.9
headers/static libraries. No NuttX or SDK source was changed.

## Results

- AP-SMP/AP-UP build selection was corrected to use the shared AP base source
  list instead of the unused UP-only path.
- Kconfig dependency loops were removed, analog upper-half dependencies were
  made explicit, and the RTC architecture hooks required by `CONFIG_RTC` were
  supplied by the BK7258 wrapper.
- The LCD framebuffer was moved from a 307,200-byte static SRAM allocation to
  a 16-byte-aligned allocation from the existing AP PSRAM heap.
- AP-SMP configure, compile, link and CRC post-processing passed with AUD and
  the other non-PWM wrappers enabled.
- The same flow passed with microphone capture replacing AUD, proving the
  mutually exclusive audio configurations both compile.

The resulting test image was not flashed. GPIO pinmux, attached device
identity, IRQ delivery, transfers and data integrity remain hardware gates.

## Exclusion

PWM is not in the build selection or Kconfig. Symbol inspection of official
v3.1.1.9 AP `libdriver.a` found no `bk_pwm_*` functions used by the candidate,
so including it would create an unsupported and misleading wrapper.
